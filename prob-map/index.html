3확률의 뜻과 활용 Ⅱ-1개념 · 15문제 →

수학적 확률 같은 정도로 기대될 때
$P(A)=\dfrac{n(A)}{n(S)}$
사건 $A$가 일어나는 경우의 수 ÷ 전체 경우의 수
통계적 확률
시행을 $n$번 반복해 $A$가 $r$번 일어나면, $n$이 클수록 상대도수 $\dfrac rn$이 일정한 값에 가까워진다 (큰 수의 법칙)
표본공간 $S$, 사건 $A,B$
기본 성질과 덧셈정리
$0\le P(A)\le1,\quad P(S)=1,\quad P(\varnothing)=0$
$P(A\cup B)=P(A)+P(B)-P(A\cap B)$
배반사건($A\cap B=\varnothing$)이면 $P(A\cup B)=P(A)+P(B)$
여사건 $P(A^c)=1-P(A)$  ← "적어도 하나", "~이 아닌"일 때
➜

4조건부확률과 독립 Ⅱ-2개념 · 15문제 →

조건부확률
$P(B|A)=\dfrac{P(A\cap B)}{P(A)}$
단, $P(A)\gt0$ · 표본공간을 $A$로 줄여서 본다
곱셈정리
$P(A\cap B)=P(A)\,P(B|A)$
가지를 따라 곱하고 갈래끼리 더한다: $P(B)=P(A)P(B|A)+P(A^c)P(B|A^c)$
수형도: 가지를 따라 곱하고, 같은 결과끼리 더한다
독립 서로 영향을 주지 않음
$P(B|A)=P(B)$
$\iff P(A\cap B)=P(A)P(B)$
배반($A\cap B=\varnothing$)과 독립은 다르다! 확률이 0이 아닌 두 사건이 배반이면 독립이 아니다.
독립시행의 확률
한 번에 일어날 확률이 $p$인 시행을 $n$번 독립적으로 반복할 때 $r$번 일어날 확률 ($q=1-p$)
${}_nC_r\,p^r\,q^{n-r}$
→ 통계의 이항분포로 이어진다
핵심 흐름 : 경우의 수를 세고 → 확률을 구하고 → 조건부확률과 독립을 판단한다 → 독립시행은 이항분포로

1앞 단원에서 가져올 것

이항정리 ↗
$(a+b)^n=\sum{}_nC_r\,a^{n-r}b^r$
독립시행의 확률 ↗
$P(X=r)={}_nC_r\,p^rq^{n-r}$
✔ 이항분포 = 독립시행에서 성공 횟수 $X$의 확률분포. 각 확률을 모두 더하면 이항정리에 의해 $(p+q)^n=1$

2이산확률변수 개념 · 15문제 →

$P(X=x_i)=p_i,\ \ \sum p_i=1$
평균 $E(X)=\sum x_ip_i$
분산 $V(X)=E(X^2)-\{E(X)\}^2$ (제평−평제)
표준편차 $\sigma(X)=\sqrt{V(X)}$
$E(aX+b)=aE(X)+b$
$V(aX+b)=a^2V(X),\ \sigma(aX+b)=|a|\sigma(X)$

3이산확률분포 : 이항분포개념 · 15문제 →

$X\sim B(n,p)$
$E(X)=np,\ V(X)=npq,\ \sigma(X)=\sqrt{npq}$
이항분포의 정규분포 근사
개념 · 15문제 →
$n$이 충분히 크면
$B(n,p)\ \approx\ N(np,\ npq)$
$np\Rightarrow m,\ \sqrt{npq}\Rightarrow\sigma$ 로 바꿔 표준화
큰 수의 법칙(상대도수 → 확률)과는 다른 이야기

4연속확률분포 : 정규분포개념 · 15문제 →

확률밀도함수
$f(x)\ge0$, 그래프와 $x$축 사이 전체 넓이 $=1$
$P(a\le X\le b)=$ 그 구간의 넓이
한 점의 확률 $P(X=a)=0$
$X\sim N(m,\sigma^2)$
$x=m$에 대칭인 종 모양
$\sigma$가 클수록 낮고 넓게 퍼짐
$m\pm\sigma$ 약 68%, $m\pm2\sigma$ 약 95%
면적이 확률! (곡선의 높이가 아님)

5표준정규분포와 표준화개념 · 15문제 →

$Z=\dfrac{X-m}{\sigma}\ \sim\ N(0,1)$
표준정규분포표로 $P(0\le Z\le z)$를 읽는다. $P(Z\ge0)=0.5$
예: $P(0\le Z\le1)\approx0.3413,\ P(0\le Z\le2)\approx0.4772$
평균을 빼서 중심을 0으로, 표준편차로 나눠 퍼짐을 1로 맞춘다.
"평균에서 얼마나 떨어졌나?" → "표준편차 몇 개만큼인가?"

6표본평균의 분포 개념 · 15문제 →

모집단 → 크기 $n$인 표본을 임의추출
$E(\overline X)=m,\ V(\overline X)=\dfrac{\sigma^2}{n},\ \sigma(\overline X)=\dfrac{\sigma}{\sqrt n}$
$\overline X\sim N\!\left(m,\ \dfrac{\sigma^2}{n}\right)$
모집단이 정규분포이면 정확히, 아니어도 $n$이 크면 근사적으로 성립
$\sigma$를 모르면 $n$이 클 때 표본표준편차 $s$를 대신 쓴다
➜

7모평균의 추정개념 · 15문제 →

$P\!\left(-1.96\le\dfrac{\overline X-m}{\sigma/\sqrt n}\le1.96\right)=0.95$
신뢰도 95% : $\overline x-1.96\dfrac{\sigma}{\sqrt n}\le m\le\overline x+1.96\dfrac{\sigma}{\sqrt n}$
신뢰도 99% : $\overline x\pm2.58\dfrac{\sigma}{\sqrt n}$
신뢰구간의 길이 $=2k\dfrac{\sigma}{\sqrt n}$ → $n$을 4배로 하면 길이는 $\dfrac12$

8모비율의 추정 개념 · 15문제 →

2022 개정에서 새로 들어온 내용
표본비율 $\hat p=\dfrac Xn,\ \ \hat q=1-\hat p$
$n$이 충분히 크면 $\hat p\approx N\!\left(p,\dfrac{pq}{n}\right)$
신뢰도 95% : $\hat p\pm1.96\sqrt{\dfrac{\hat p\hat q}{n}}$
계산기·스프레드시트 같은 공학 도구를 활용
