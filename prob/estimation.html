통계적 추정

Ⅲ 통계 · 모집단과 표본 · 모평균의 추정 · 모비율의 추정

한 줄로 외우기

전체(모집단)를 다 조사할 수 없으니 일부(표본)를 뽑아 전체를 짐작한다. 표본평균의 분포를 알면 "모평균은 이 구간 안에 있을 것이다"를 신뢰도와 함께 말할 수 있다.

왜 배울까?여론조사, 시청률, 공장의 품질검사는 모두 표본으로 전체를 추정한다. 뉴스에 나오는 "신뢰수준 95%, 표본오차 ±3.1%p"가 무슨 뜻인지 읽을 수 있게 된다.

  • 모집단과 표본
  • 모평균의 추정
  • 모비율의 추정

1모집단과 표본

조사 대상 전체가 모집단, 그중 뽑은 일부가 표본이다. 표본은 모집단의 각 대상이 뽑힐 확률이 같도록 임의추출해야 한다. 모집단의 평균 m(모평균), 표준편차 σ(모표준편차)에 대해 크기 n인 표본의 평균 X̄(표본평균)는

E(X̄) = m
V(X̄) = σ2n,  σ(X̄) = σ√n

모집단이 정규분포이면 X̄는 N(m, σ2/n)을 따르고, 모집단이 정규분포가 아니어도 n이 충분히 크면 근사적으로 그렇다. 표본이 클수록 X̄는 m 근처에 더 모인다.

2모평균의 추정

표본평균 x̄로 모평균 m이 들어 있을 구간(신뢰구간)을 추정한다.

신뢰도 95%x̄ − 1.96σ√n ≤ m ≤ x̄ + 1.96σ√n
신뢰도 99%x̄ − 2.58σ√n ≤ m ≤ x̄ + 2.58σ√n
예
n = 100, x̄ = 170, σ = 10 → 1.96 × 10/10 = 1.96 → 168.04 ≤ m ≤ 171.96 (신뢰도 95%)
뜻
"95% 신뢰구간"은 같은 방법으로 표본을 여러 번 뽑아 구간을 만들면 그중 약 95%가 모평균을 포함한다는 뜻이다. 표본 크기를 4배로 하면 구간의 길이는 절반이 된다.

3모비율의 추정

찬성률처럼 "비율"을 추정할 때는 표본비율 p̂ = X/n을 쓴다. n이 충분히 크면 p̂는 근사적으로 정규분포 N(p, pq/n)을 따르므로, 모평균과 같은 방법으로 신뢰구간을 만든다(q̂ = 1 − p̂).

신뢰도 95%:  p̂ − 1.96√p̂q̂/n ≤ p ≤ p̂ + 1.96√p̂q̂/n
예
400명 중 240명 찬성 → p̂ = 0.6, √(0.6 × 0.4/400) ≈ 0.0245, × 1.96 ≈ 0.048 → 0.552 ≤ p ≤ 0.648

계산이 복잡하므로 교과서에서는 계산기, 스프레드시트 같은 공학 도구를 이용해 모비율을 추정하기도 한다.

꼭 외울 것

  • E(X̄) = m, σ(X̄) = σ/√n
  • 95% → 1.96, 99% → 2.58
  • 모평균 신뢰구간: x̄ ± z·σ/√n
  • 모비율 신뢰구간: p̂ ± z·√(p̂q̂/n)
  • 표본 4배 → 구간 길이 1/2

확인 문제

1모표준편차 12, 표본 크기 36일 때 σ(X̄)는?답 보기
12/√36 = 2
2표본 크기를 4배로 늘리면 신뢰구간의 길이는?답 보기
√4 = 2로 나누어지므로 1/2
3n = 100, x̄ = 50, σ = 5일 때 모평균의 95% 신뢰구간은?답 보기
1.96 × 5/10 = 0.98 → 49.02 ≤ m ≤ 50.98
