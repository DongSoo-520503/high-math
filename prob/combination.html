중복조합과 이항정리

Ⅰ 경우의 수 · 중복조합 · 이항정리 · 파스칼의 삼각형

한 줄로 외우기

중복을 허락해 순서 없이 r개 고르는 수는 nHr = n+r−1Cr이다. (a + b)n을 펼친 각 항의 계수는 조합 nCr이다.

왜 배울까?같은 사탕을 여러 명에게 나눠 주는 방법, 방정식 x + y + z = 10의 정수해 개수가 중복조합이다. 이항정리는 (a + b)n을 일일이 곱하지 않고 한 번에 전개하며, 뒤에 나오는 이항분포의 바탕이 된다.

  • 이항정리

1중복조합

서로 다른 n종류에서 중복을 허락하여 순서 없이 r개를 고르는 방법의 수를 nHr로 쓴다.

nHr = n+r−1Cr

고른 r개(●)와 종류를 나누는 칸막이 n − 1개(|)를 한 줄로 늘어놓는다고 생각하면, n + r − 1자리 중 ●의 자리 r개를 고르는 것과 같다.

예
사과·배·감 중에서 5개 고르기(같은 과일 여러 개 가능) → 3H5 = 7C5 = 21가지
x + y + z = 6의 음이 아닌 정수해 → 3H6 = 8C6 = 28개

2이항정리

(a + b)n = nC0an + nC1an−1b + … + nCran−rbr + … + nCnbn

n개의 괄호 (a + b)에서 b를 고를 괄호 r개를 정하는 방법이 nCr가지이므로 an−rbr의 계수가 nCr가 된다. nCran−rbr을 일반항이라 한다.

예
(x + 2)4에서 x2의 계수 → 4C2 · 22 = 6 × 4 = 24

a = b = 1을 넣으면 nC0 + nC1 + … + nCn = 2n을 얻는다.

꼭 외울 것

  • 일반항 nCran−rbr
  • nC0 + … + nCn = 2n
