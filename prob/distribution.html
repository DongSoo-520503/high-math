확률분포

Ⅲ 통계 · 이산확률변수 · 이항분포 · 정규분포

한 줄로 외우기

확률변수는 결과에 붙인 숫자이고, 확률분포는 각 값이 나올 확률의 표다. 평균(기댓값)은 "확률을 곱해 더한 값", 분산은 퍼진 정도다.

왜 배울까?중3 산포도에서는 이미 모은 자료의 평균과 분산을 구했다. 이번에는 아직 일어나지 않은 결과의 평균과 분산을 확률로 계산한다. 정규분포는 키, 시험 점수처럼 자연과 사회에서 가장 흔한 분포 모양이다.

  • 이산확률변수
  • 이항분포
  • 정규분포

1이산확률변수

확률변수 X가 x1, x2, …처럼 셀 수 있는 값을 가지면 이산확률변수다. P(X = xi) = pi일 때 확률의 합 Σpi = 1이다.

평균(기댓값)E(X) = Σxipi
분산V(X) = E(X2) − {E(X)}2
표준편차σ(X) = √V(X)
aX + bE(aX + b) = aE(X) + b,  V(aX + b) = a2V(X)
예
동전 2개를 던질 때 앞면의 수 X: 0, 1, 2의 확률이 1/4, 1/2, 1/4
E(X) = 0 + 1/2 + 2/4 = 1, E(X2) = 0 + 1/2 + 4/4 = 3/2, V(X) = 3/2 − 1 = 1/2

2이항분포

한 번에 성공할 확률이 p인 독립시행을 n번 할 때, 성공 횟수 X의 분포를 이항분포 B(n, p)라 한다(q = 1 − p).

P(X = r) = nCrprqn−r
E(X) = np,  V(X) = npq
예
B(100, 1/5): E(X) = 20, V(X) = 100 × 1/5 × 4/5 = 16, σ(X) = 4

3정규분포

키처럼 연속적인 값을 갖는 확률변수는 확률밀도함수의 그래프 아래 넓이가 확률이다. 평균 m, 표준편차 σ인 정규분포 N(m, σ2)는 x = m에 대칭인 종 모양이다.

표준화 Z = (X − m)/σ를 하면 Z는 표준정규분포 N(0, 1)을 따르고, 표준정규분포표로 확률을 구한다. 또 n이 충분히 크면 이항분포 B(n, p)는 정규분포 N(np, npq)에 가까워진다.

예
평균 60점, 표준편차 10점인 시험에서 70점 이상일 비율
Z = (70 − 60)/10 = 1 → P(Z ≥ 1) = 0.5 − 0.3413 = 0.1587 (약 16%)

꼭 외울 것

  • Σpi = 1
  • E(X) = Σxp, V(X) = E(X²) − {E(X)}²
  • E(aX + b) = aE + b, V(aX + b) = a²V
  • B(n, p): E = np, V = npq
  • 표준화 Z = (X − m)/σ

확인 문제

1E(X) = 3일 때 Y = 2X + 1의 평균은?답 보기
2 × 3 + 1 = 7
2B(50, 0.2)의 분산은?답 보기
50 × 0.2 × 0.8 = 8
3X가 N(50, 42)을 따를 때 P(X ≥ 58)은? (P(0 ≤ Z ≤ 2) = 0.4772)답 보기
Z = (58 − 50)/4 = 2 → 0.5 − 0.4772 = 0.0228
