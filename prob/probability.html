확률의 뜻과 활용

한 줄로 외우기

확률은 "그 사건이 일어나는 경우의 수 ÷ 모든 경우의 수"다. "A 또는 B"의 확률은 두 확률을 더한 뒤 겹친 부분을 한 번 뺀다.

왜 배울까?중2에서 배운 확률을 집합의 언어로 다시 정리한다. 사건을 집합으로 보면 복잡한 확률도 벤 다이어그램처럼 계산할 수 있다.

1시행과 사건

시행같은 조건에서 반복할 수 있고, 결과가 우연에 의해 정해지는 실험·관찰
표본공간 S일어날 수 있는 모든 결과의 집합
사건표본공간의 부분집합
배반사건A ∩ B = ∅ (동시에 일어나지 않음)
여사건 ACA가 일어나지 않는 사건
예
주사위 하나를 던지는 시행: S = {1, 2, 3, 4, 5, 6}, "짝수의 눈" A = {2, 4, 6}, AC = {1, 3, 5}

2수학적·통계적 확률

각 결과가 일어날 가능성이 모두 같을 때 수학적 확률은

P(A) = n(A)n(S)

같은 시행을 n번 반복해 A가 r번 일어났을 때, n을 크게 하면 상대도수 r/n이 일정한 값에 가까워진다. 이 값이 통계적 확률이다. 어떤 확률이든 0 ≤ P(A) ≤ 1, P(S) = 1, P(∅) = 0이다.

3확률의 덧셈정리

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

A와 B가 배반사건이면 겹치는 부분이 없으므로 P(A ∪ B) = P(A) + P(B). 또 여사건의 확률은 P(AC) = 1 − P(A)다.

예
1~20 카드 중 한 장이 2의 배수 또는 3의 배수일 확률
10/20 + 6/20 − 3/20 = 13/20 (6의 배수 3장이 두 번 세어짐)
여사건
동전 3개를 던져 앞면이 적어도 하나 나올 확률 → 1 − (모두 뒷면) = 1 − 1/8 = 7/8
요령
"적어도 하나", "~이 아닌"이 나오면 여사건으로 계산하는 편이 훨씬 빠르다.

꼭 외울 것

  • P(A) = n(A)/n(S)
  • 0 ≤ P(A) ≤ 1
  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • P(AC) = 1 − P(A)
  • "적어도" → 여사건

확인 문제

1주사위 2개를 던져 눈의 합이 7일 확률은?답 보기
(1,6), (2,5), …, (6,1)의 6가지 → 6/36 = 1/6
2P(A) = 0.5, P(B) = 0.4, P(A ∩ B) = 0.2일 때 P(A ∪ B)는?답 보기
0.5 + 0.4 − 0.2 = 0.7
34명 중 2명을 뽑을 때 특정한 사람 갑이 포함될 확률은?답 보기
1 − (갑 없이 뽑기) = 1 − 3C2/4C2 = 1 − 3/6 = 1/2
