# 고등수학 목차 및 개념

> 나무를 보느라 숲을 보지 못한다! 목차도 외우지 못하면 수학을 포기하는 것과 같다.

2022 개정 교육과정 고등학교 수학 전체 목차를 **1학년 → 2학년 → 확률과 통계 → 미적분Ⅱ → 기하**
순서로 한눈에 보고, 각 항목을 누르면 개념설명·예시·확인 문제를 볼 수 있는 선행학습 사이트입니다.
설명은 중학수학을 마친 학생 눈높이로 썼습니다.

## 폴더 구조

```
index.html        목차 지도 (첫 화면, 6줄 × 5열 + 확률과 통계 개념관계도·미적분 계산 총정리 블록)
assets/           style.css, app.js (공통)
calc-drill/       미적분 계산 총정리 (표 + 블록별 연습문제 15개, 24블록)
prob-map/         확률과 통계 개념관계도 (관계도 + 블록별 개념·연습문제 15개, 13블록)
h1/               1학년 공통수학1·2 (6개)
h2/               2학년 대수·미적분Ⅰ (6개)
prob/             확률과 통계 (6개)
calc/             미적분Ⅱ (6개)
geom/             기하 (6개)
```

## 수능과 내신

| 과목 | 2028학년도 이후 수능 | 내신 |
|---|---|---|
| 공통수학1·2 | 직접 출제 ✗ (모든 과목의 기초) | ○ |
| 대수, 미적분Ⅰ, 확률과 통계 | ○ (선택과목 없이 공통 출제) | ○ |
| 미적분Ⅱ, 기하 | ✗ | ○ (이공계 학과 이수 권장) |

## GitHub Pages로 공개하기

1. 이 폴더의 내용을 저장소(예: `high-math`) 최상위에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서
   Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 잠시 후 `https://<사용자이름>.github.io/high-math/` 에서 열립니다.

### 중학수학 목차 및 개념과 연결

첫 화면과 "먼저 알아야 할 것"의 ↗ 표시 링크는 Vercel에 올린 중학수학 목차 및 개념
(`https://middle-math.vercel.app/`) 페이지로 갑니다.

## 기능

- **목차 가리고 외우기**: 항목을 가린 뒤 하나씩 눌러 확인
- **✓ 이해 표시**: 단원별 이해 여부를 브라우저에 저장 (기기마다 따로 저장됨)
- 단원마다 한 줄 요약, 왜 배울까, 중단원별 설명과 그래프, 꼭 외울 것, 확인 문제 3개, 앞뒤 연결 단원
- 라이트/다크 모드 자동 대응, 휴대폰 화면 대응
