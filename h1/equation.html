한 줄로 외우기

제곱해서 −1이 되는 수 i를 만들면 모든 이차방정식이 근을 갖는다. 방정식과 부등식은 그래프가 x축과 만나는 모양으로 한눈에 풀린다.

왜 배울까?중3에서는 x2 = −1 같은 방정식은 "해가 없다"고 했다. 수를 복소수까지 넓히면 이런 방정식도 풀 수 있다. 또 이차함수 그래프와 연결하면 부등식과 최대·최소 문제까지 한 그림으로 해결된다.

1복소수와 이차방정식

i2 = −1인 수 i를 허수단위라 한다. a + bi (a, b는 실수) 꼴의 수를 복소수라 하고, a를 실수부분, b를 허수부분이라 한다. a − bi는 a + bi의 켤레복소수다. 계산은 i를 문자처럼 다루다가 i2이 나오면 −1로 바꾸면 된다.

예
(2 + 3i)(1 − i) = 2 − 2i + 3i − 3i2 = 2 + i + 3 = 5 + i

이차방정식 ax2 + bx + c = 0의 근이 어떤 수인지는 근의 공식 속 √ 안의 값, 판별식 D = b2 − 4ac로 판단한다.

판별식근
D > 0서로 다른 두 실근
D = 0중근(실근)
D < 0서로 다른 두 허근

두 근을 α, β라 하면 근을 직접 구하지 않아도 합과 곱을 안다(근과 계수의 관계).

α + β = −ba ,   αβ = ca
예
x2 − 4x + 13 = 0 → x = 2 ± 3i. 합 4, 곱 (2 + 3i)(2 − 3i) = 4 + 9 = 13. 공식과 같다.

2이차방정식과 이차함수

이차함수 y = ax2 + bx + c의 그래프가 x축과 만나는 점의 x좌표가 곧 이차방정식 ax2 + bx + c = 0의 실근이다. 그래서 판별식의 부호가 교점의 개수를 알려 준다(D > 0이면 2개, D = 0이면 접함, D < 0이면 만나지 않음). 직선 y = mx + n과의 위치 관계도 두 식을 같다고 놓은 이차방정식의 판별식으로 판단한다.

x의 범위가 정해진 이차함수의 최대·최소는 꼭짓점과 양 끝점의 함숫값을 비교해서 구한다.

예
1 ≤ x ≤ 4에서 y = x2 − 2x − 3 = (x − 1)2 − 4
최솟값: x = 1일 때 −4, 최댓값: x = 4일 때 16 − 8 − 3 = 5

3여러 가지 방정식과 부등식

삼차·사차방정식은 인수분해(인수정리)로 차수를 낮춰 푼다. 연립이차방정식은 일차식을 한 문자에 대해 풀어 대입한다.

예
x4 − 5x2 + 4 = 0 → (x2 − 1)(x2 − 4) = 0 → x = ±1, ±2

이차부등식은 그래프로 푼다. ax2 + bx + c > 0의 해는 그래프가 x축 위에 있는 x의 범위, < 0은 아래에 있는 범위다. 위 그림에서

x2 − 2x − 3 < 0−1 < x < 3 (두 근 사이)
x2 − 2x − 3 > 0x < −1 또는 x > 3 (두 근 바깥)

절댓값 부등식 |x − a| < k는 "a에서의 거리가 k보다 작다"는 뜻이다.

예
|x − 1| < 3 → −3 < x − 1 < 3 → −2 < x < 4

꼭 외울 것

  • i2 = −1
  • 판별식 D = b2 − 4ac (양수: 두 실근, 0: 중근, 음수: 두 허근)
  • α + β = −b/a, αβ = c/a
  • 이차부등식 = 그래프가 x축 위(>0)·아래(<0)인 범위
  • 제한된 범위의 최대·최소: 꼭짓점과 양 끝 비교
