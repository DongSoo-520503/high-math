한 줄로 외우기

제곱해서 −1이 되는 수 i를 만들면 모든 이차방정식이 근을 갖는다. 방정식과 부등식은 그래프가 x축과 만나는 모양으로 한눈에 풀린다.

왜 배울까?중3에서는 x2 = −1 같은 방정식은 "해가 없다"고 했다. 수를 복소수까지 넓히면 이런 방정식도 풀 수 있다. 또 이차함수 그래프와 연결하면 부등식과 최대·최소 문제까지 한 그림으로 해결된다.

1복소수와 이차방정식

i2 = −1인 수 i를 허수단위라 한다. a + bi (a, b는 실수) 꼴의 수를 복소수라 하고, a를 실수부분, b를 허수부분이라 한다. a − bi는 a + bi의 켤레복소수다. 계산은 i를 문자처럼 다루다가 i2이 나오면 −1로 바꾸면 된다.

예
(2 + 3i)(1 − i) = 2 − 2i + 3i − 3i2 = 2 + i + 3 = 5 + i

이차방정식 ax2 + bx + c = 0의 근이 어떤 수인지는 근의 공식 속 √ 안의 값, 판별식 D = b2 − 4ac로 판단한다.

판별식근
D > 0서로 다른 두 실근
D = 0중근(실근)
D < 0서로 다른 두 허근

두 근을 α, β라 하면 근을 직접 구하지 않아도 합과 곱을 안다(근과 계수의 관계).

α + β = −ba ,   αβ = ca
예
x2 − 4x + 13 = 0 → x = 2 ± 3i. 합 4, 곱 (2 + 3i)(2 − 3i) = 4 + 9 = 13. 공식과 같다.

2이차방정식과 이차함수

이차함수 y = ax2 + bx + c의 그래프가 x축과 만나는 점의 x좌표가 곧 이차방정식 ax2 + bx + c = 0의 실근이다. 그래서 판별식의 부호가 교점의 개수를 알려 준다(D > 0이면 2개, D = 0이면 접함, D < 0이면 만나지 않음). 직선 y = mx + n과의 위치 관계도 두 식을 같다고 놓은 이차방정식의 판별식으로 판단한다.

x의 범위가 정해진 이차함수의 최대·최소는 꼭짓점과 양 끝점의 함숫값을 비교해서 구한다.

예
1 ≤ x ≤ 4에서 y = x2 − 2x − 3 = (x − 1)2 − 4
최솟값: x = 1일 때 −4, 최댓값: x = 4일 때 16 − 8 − 3 = 5

3여러 가지 방정식과 부등식

삼차·사차방정식은 인수분해(인수정리)로 차수를 낮춰 푼다. 연립이차방정식은 일차식을 한 문자에 대해 풀어 대입한다.

예
x4 − 5x2 + 4 = 0 → (x2 − 1)(x2 − 4) = 0 → x = ±1, ±2

이차부등식은 그래프로 푼다. ax2 + bx + c > 0의 해는 그래프가 x축 위에 있는 x의 범위, < 0은 아래에 있는 범위다. 위 그림에서

x2 − 2x − 3 < 0−1 < x < 3 (두 근 사이)
x2 − 2x − 3 > 0x < −1 또는 x > 3 (두 근 바깥)

절댓값 부등식 |x − a| < k는 "a에서의 거리가 k보다 작다"는 뜻이다.

예
|x − 1| < 3 → −3 < x − 1 < 3 → −2 < x < 4

꼭 외울 것

  • i2 = −1
  • 판별식 D = b2 − 4ac (양수: 두 실근, 0: 중근, 음수: 두 허근)
  • α + β = −b/a, αβ = c/a
  • 이차부등식 = 그래프가 x축 위(>0)·아래(<0)인 범위
  • 제한된 범위의 최대·최소: 꼭짓점과 양 끝 비교

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$(2+3i)(1-i)$를 계산하시오.
풀이
$2-2i+3i-3i^2=2+i+3=5+i$
2
$\dfrac{1+i}{1-i}$를 계산하시오.
풀이
분모의 켤레 $1+i$를 곱한다: $\dfrac{(1+i)^2}{(1-i)(1+i)}=\dfrac{2i}{2}=i$
3
이차방정식 $x^2-4x+7=0$을 푸시오.
풀이
근의 공식(짝수 공식): $x=2\pm\sqrt{4-7}=2\pm\sqrt3\,i$
4
$x^2+2x+k=0$이 서로 다른 두 실근을 가질 때 실수 $k$의 값의 범위를 구하시오.
풀이
$\dfrac D4=1-k\gt0$ → $k\lt1$
5
$x^2-5x+3=0$의 두 근을 $\alpha,\beta$라 할 때 $\alpha^2+\beta^2$의 값을 구하시오.
풀이
근과 계수의 관계: $\alpha+\beta=5,\ \alpha\beta=3$
$\alpha^2+\beta^2=(\alpha+\beta)^2-2\alpha\beta=25-6=19$

교과서 응용6–10번

6
이차함수 $y=x^2-6x+5$의 최솟값을 구하시오.
풀이
$y=(x-3)^2-4$ → $x=3$에서 최솟값 $-4$
7
직선 $y=x+k$가 포물선 $y=x^2$에 접할 때 $k$의 값을 구하시오.
풀이
$x^2=x+k$ → $x^2-x-k=0$의 판별식 $D=1+4k=0$
$k=-\dfrac14$
8
연립방정식 $x+y=5,\ xy=6$의 해 중 $x\gt y$인 것을 구하시오.
풀이
$x,y$는 $t^2-5t+6=0$의 두 근 $t=2,3$
$x\gt y$이므로 $x=3,\ y=2$
9
연립부등식 $2x-1\gt3,\ x+2\le8$을 푸시오.
풀이
$x\gt2$이고 $x\le6$ → $2\lt x\le6$
10
이차부등식 $x^2-x-6\lt0$을 푸시오.
풀이
$(x+2)(x-3)\lt0$ → $-2\lt x\lt3$

내신·수능 심화11–15번

11
$x^3=1$의 한 허근을 $\omega$라 할 때 $\omega^{10}+\omega^5+1$의 값을 구하시오.
풀이
$\omega^3=1,\ \omega^2+\omega+1=0$
$\omega^{10}=\omega,\ \omega^5=\omega^2$ → $\omega+\omega^2+1=0$
12
$0\le x\le3$에서 $y=-x^2+2x+3$의 최댓값과 최솟값을 구하시오.
풀이
$y=-(x-1)^2+4$, 꼭짓점 $x=1$이 구간 안 → 최댓값 $4$
양 끝: $x=0$에서 $3$, $x=3$에서 $0$ → 최솟값 $0$
13
모든 실수 $x$에 대하여 $x^2-2kx+k+2\gt0$이 성립하도록 하는 실수 $k$의 값의 범위를 구하시오.
풀이
$\dfrac D4=k^2-(k+2)\lt0$ → $(k+1)(k-2)\lt0$ → $-1\lt k\lt2$
14
사차방정식 $x^4-5x^2+6=0$을 푸시오.
풀이
$x^2=X$: $X^2-5X+6=0$ → $X=2,3$
$x=\pm\sqrt2,\ \pm\sqrt3$
15
$|x-1|\lt3$과 $x^2-4x\le0$을 동시에 만족하는 정수 $x$의 개수를 구하시오.
풀이
$|x-1|\lt3$ → $-2\lt x\lt4$
$x(x-4)\le0$ → $0\le x\le4$
공통: $0\le x\lt4$ → $0,1,2,3$의 $4$개
