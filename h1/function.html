함수와 그래프

공통수학2 · 함수 · 유리함수와 무리함수

한 줄로 외우기

함수는 X의 원소마다 Y의 원소를 딱 하나씩 짝짓는 규칙이다. 합성함수는 규칙을 이어 붙인 것, 역함수는 거꾸로 되돌리는 것이다.

왜 배울까?중학교에서는 일차·이차함수의 그래프를 그렸다. 고등학교에서는 함수 자체를 정의하고, 이어 붙이고, 거꾸로 돌리는 법을 배운다. 지수·로그·삼각함수와 미적분이 모두 이 위에 세워진다.

1함수

집합 X의 각 원소에 집합 Y의 원소가 오직 하나씩 대응할 때 이를 X에서 Y로의 함수라 한다. X는 정의역, Y는 공역, 실제로 나오는 함숫값의 집합은 치역이다.

일대일함수서로 다른 x에 서로 다른 y가 대응
일대일대응일대일함수이면서 치역 = 공역
항등함수f(x) = x
상수함수f(x) = c

합성함수 (g ∘ f)(x) = g(f(x)): f를 먼저, 그 결과에 g를 적용한다. 일반적으로 g ∘ f ≠ f ∘ g.

역함수 f−1는 y = f(x)를 x에 대해 풀고 x와 y를 바꾸어 얻는다. 일대일대응일 때만 존재하고, y = f(x)와 y = f−1(x)의 그래프는 직선 y = x에 대칭이다.

예
f(x) = 2x + 1, g(x) = x2
(g ∘ f)(1) = g(3) = 9, (f ∘ g)(1) = f(1) = 3 → 순서가 바뀌면 값이 다르다
y = 2x + 1 → x = (y − 1)/2 → f−1(x) = x − 12

2유리함수와 무리함수

분모에 x가 있는 함수가 유리함수다. 기본형 y = k/x(중1 반비례)를 평행이동한 꼴로 정리하면 그래프를 바로 그릴 수 있다.

y = kx − p + q  →  점근선: x = p, y = q

√ 안에 x가 있는 함수가 무리함수다. y = √(a(x − p)) + q는 y = √(ax)를 평행이동한 것으로, 시작점이 (p, q)이다. √ 안이 0 이상이어야 하므로 정의역에 주의한다.

꼭 외울 것

  • 함수: x 하나에 y가 오직 하나
  • (g ∘ f)(x) = g(f(x)), 순서 주의
  • 역함수는 일대일대응일 때만, y = x에 대칭
  • y = k/(x − p) + q의 점근선 x = p, y = q
  • 무리함수: √ 안 ≥ 0

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$f(x)=2x+1,\ g(x)=x^2$일 때 $(g\circ f)(1)$의 값을 구하시오.
풀이
$f(1)=3$, $g(3)=9$
2
$f(x)=3x-2$의 역함수를 구하시오.
풀이
$y=3x-2$를 $x$에 대해 풀면 $x=\dfrac{y+2}3$ → $f^{-1}(x)=\dfrac{x+2}3$
3
유리함수 $y=\dfrac{2}{x-1}+3$의 점근선을 구하시오.
풀이
$x=1$, $y=3$
4
무리함수 $y=\sqrt{x-2}+1$의 정의역과 치역을 구하시오.
풀이
$x-2\ge0$ → 정의역 $\{x\mid x\ge2\}$, 치역 $\{y\mid y\ge1\}$
5
$X=\{1,2,3\}$에서 $Y=\{a,b\}$로의 함수의 개수를 구하시오.
풀이
정의역의 원소마다 2가지 → $2^3=8$

교과서 응용6–10번

6
$f(x)=x+1,\ g(x)=2x$일 때 $(f\circ g)(3)-(g\circ f)(3)$의 값을 구하시오.
풀이
$(f\circ g)(3)=f(6)=7$, $(g\circ f)(3)=g(4)=8$ → $-1$
(합성은 순서를 바꾸면 결과가 달라진다)
7
$y=\dfrac{2x+1}{x-1}$의 점근선을 구하시오.
풀이
$\dfrac{2x+1}{x-1}=\dfrac{2(x-1)+3}{x-1}=2+\dfrac3{x-1}$
점근선 $x=1,\ y=2$
8
일차함수 $f(x)=ax+b$에 대하여 $f(1)=3,\ f^{-1}(7)=3$일 때 $f(5)$의 값을 구하시오.
풀이
$f^{-1}(7)=3$ ⇔ $f(3)=7$
$a+b=3,\ 3a+b=7$ → $a=2,\ b=1$ → $f(5)=11$
9
곡선 $y=\sqrt{2x+4}$와 직선 $y=x$의 교점의 $x$좌표를 구하시오.
풀이
$\sqrt{2x+4}=x$ ($x\ge0$) → $x^2-2x-4=0$ → $x=1\pm\sqrt5$
$x\ge0$이므로 $x=1+\sqrt5$
10
$X=\{1,2,3\}$에서 $Y=\{4,5,6\}$으로의 일대일대응의 개수를 구하시오.
풀이
$3!=6$

내신·수능 심화11–15번

11
$f(x)=x^2-2x\ (x\ge1)$의 역함수를 $g(x)$라 할 때 $g(3)$의 값을 구하시오.
풀이
$g(3)=k$ ⇔ $f(k)=3$: $k^2-2k-3=0$ → $k=3$ ($k\ge1$)
12
유리함수 $y=\dfrac{3x+k}{x+1}$의 그래프가 점 $(1,2)$를 지날 때 $k$의 값을 구하시오.
풀이
$\dfrac{3+k}2=2$ → $k=1$
13
$f(x)=\sqrt{x+2}$의 그래프와 그 역함수의 그래프의 교점을 구하시오.
풀이
증가함수의 그래프와 역함수 그래프의 교점은 $y=x$ 위에 있다
$\sqrt{x+2}=x$ → $x^2-x-2=0$ → $x=2$ ($x\ge0$) → $(2,2)$
14
$f(x)=\dfrac{x+1}{x-1}$일 때 $f(f(f(3)))$의 값을 구하시오.
풀이
$f(3)=2,\ f(2)=3,\ f(3)=2$
(사실 $f(f(x))=x$이다) → $2$
15
직선 $y=x+k$와 곡선 $y=\sqrt x$가 서로 다른 두 점에서 만나도록 하는 $k$의 값의 범위를 구하시오.
풀이
$\sqrt x=t\ (t\ge0)$로 놓으면 $t^2-t+k=0$이 음이 아닌 서로 다른 두 근
$D=1-4k\gt0$, 두 근의 곱 $k\ge0$ → $0\le k\lt\dfrac14$
