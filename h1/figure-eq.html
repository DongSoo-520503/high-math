한 줄로 외우기

도형을 좌표평면에 올리면 점은 순서쌍, 직선과 원은 식이 된다. 그러면 도형 문제를 계산으로 풀 수 있다.

왜 배울까?중학교 도형은 성질과 작도로 풀었다. 고등학교에서는 도형을 식으로 바꿔 계산한다. 기하의 이차곡선·벡터, 미적분의 그래프 문제가 모두 이 방법 위에 있다.

1평면좌표

두 점 A(x1, y1), B(x2, y2) 사이의 거리는 피타고라스 정리로 구한다.

AB = √(x2 − x1)2 + (y2 − y1)2

선분 AB를 m : n으로 내분하는 점과 삼각형의 무게중심은 다음과 같다.

내분점(mx2 + nx1m + n, my2 + ny1m + n)
중점(x1 + x22, y1 + y22)
무게중심(x1 + x2 + x33, y1 + y2 + y33)
예
A(1, 2), B(4, 6) → AB = √9 + 16 = 5

2직선의 방정식

기울기 m, 점 (x1, y1)을 지남y − y1 = m(x − x1)
일반형ax + by + c = 0
두 직선이 평행기울기가 같고 y절편이 다름
두 직선이 수직기울기의 곱 = −1

점 (x1, y1)과 직선 ax + by + c = 0 사이의 거리:

|ax1 + by1 + c|√a2 + b2
예
점 (1, 2)와 직선 3x + 4y − 1 = 0 사이의 거리 → |3 + 8 − 1| ÷ 5 = 2

3원의 방정식

중심이 (a, b)이고 반지름이 r인 원은 "중심에서의 거리가 r인 점들"이므로

(x − a)2 + (y − b)2 = r2

x2 + y2 + Ax + By + C = 0 꼴은 완전제곱식으로 고쳐 중심과 반지름을 찾는다. 원과 직선의 위치 관계는 중심에서 직선까지 거리 d와 반지름 r을 비교한다: d < r 두 점에서 만남, d = r 접함, d > r 만나지 않음.

예
x2 + y2 − 4x + 6y + 4 = 0 → (x − 2)2 + (y + 3)2 = 9 → 중심 (2, −3), 반지름 3

4도형의 이동

이동점도형의 식
평행이동 (x축 a, y축 b)점 (x, y) → (x + a, y + b)식 f(x, y) = 0 → f(x − a, y − b) = 0
x축 대칭(x, −y)y 대신 −y
y축 대칭(−x, y)x 대신 −x
원점 대칭(−x, −y)x, y 모두 부호 바꿈
직선 y = x 대칭(y, x)x와 y를 바꿈
주의
도형을 오른쪽으로 a만큼 옮길 때 식에서는 x 대신 x − a를 넣는다. 부호가 반대로 보이는 것에 주의!

꼭 외울 것

  • 두 점 사이 거리 = √(Δx² + Δy²)
  • m : n 내분점 = (mx₂ + nx₁)/(m + n)
  • 수직인 두 직선: 기울기의 곱 = −1
  • 점과 직선 거리 = |ax₁ + by₁ + c| / √(a² + b²)
  • 원: (x − a)² + (y − b)² = r²
  • 평행이동: x → x − a, y → y − b

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
두 점 $A(1,2),\ B(4,6)$ 사이의 거리를 구하시오.
풀이
$\sqrt{3^2+4^2}=5$
2
두 점 $A(-1,3),\ B(5,-3)$에 대하여 선분 $AB$를 $2:1$로 내분하는 점의 좌표를 구하시오.
풀이
$\left(\dfrac{2\cdot5+1\cdot(-1)}{3},\ \dfrac{2\cdot(-3)+1\cdot3}{3}\right)=(3,-1)$
3
두 점 $(1,2),\ (3,8)$을 지나는 직선의 방정식을 구하시오.
풀이
기울기 $\dfrac{8-2}{3-1}=3$ → $y-2=3(x-1)$ → $y=3x-1$
4
원 $x^2+y^2-4x+6y-3=0$의 중심과 반지름을 구하시오.
풀이
$(x-2)^2+(y+3)^2=3+4+9=16$
중심 $(2,-3)$, 반지름 $4$
5
점 $(1,2)$를 $x$축 방향으로 $3$만큼, $y$축 방향으로 $-1$만큼 평행이동한 점을 구하시오.
풀이
$(1+3,\ 2-1)=(4,1)$

교과서 응용6–10번

6
점 $(3,4)$와 직선 $3x+4y-5=0$ 사이의 거리를 구하시오.
풀이
$\dfrac{|9+16-5|}{\sqrt{3^2+4^2}}=\dfrac{20}{5}=4$
7
점 $(2,3)$을 지나고 직선 $y=2x+1$에 수직인 직선의 방정식을 구하시오.
풀이
수직이면 기울기의 곱이 $-1$ → 기울기 $-\dfrac12$
$y-3=-\dfrac12(x-2)$ → $y=-\dfrac12x+4$
8
원 $x^2+y^2=10$ 위의 점 $(1,3)$에서의 접선의 방정식을 구하시오.
풀이
원 $x^2+y^2=r^2$ 위의 점 $(x_1,y_1)$에서의 접선 $x_1x+y_1y=r^2$
→ $x+3y=10$
9
점 $(2,5)$를 직선 $y=x$에 대하여 대칭이동한 점을 구하시오.
풀이
$x,y$를 바꾼다: $(5,2)$
10
세 점 $(0,0),\ (6,0),\ (3,9)$를 꼭짓점으로 하는 삼각형의 무게중심을 구하시오.
풀이
$\left(\dfrac{0+6+3}{3},\ \dfrac{0+0+9}{3}\right)=(3,3)$

내신·수능 심화11–15번

11
원 $x^2+y^2=4$와 직선 $y=x+k$가 서로 다른 두 점에서 만나도록 하는 $k$의 값의 범위를 구하시오.
풀이
중심 $(0,0)$에서 직선 $x-y+k=0$까지 거리 $\dfrac{|k|}{\sqrt2}\lt2$
→ $-2\sqrt2\lt k\lt2\sqrt2$
12
원 $(x-1)^2+(y-2)^2=9$ 위의 점과 직선 $3x+4y+19=0$ 사이의 거리의 최솟값을 구하시오.
풀이
중심 $(1,2)$에서 직선까지 $\dfrac{|3+8+19|}{5}=6$
최솟값 $=6-3=3$
13
기울기가 $2$이고 원 $x^2+y^2=5$에 접하는 직선의 방정식을 구하시오.
풀이
$y=2x+n$이 접하려면 중심까지 거리 $=\dfrac{|n|}{\sqrt5}=\sqrt5$ → $n=\pm5$
$y=2x\pm5$
14
두 원 $x^2+y^2=9$와 $(x-4)^2+y^2=1$의 위치 관계를 말하시오.
풀이
중심 거리 $d=4$, 반지름의 합 $3+1=4$ → $d=r_1+r_2$ 이므로 외접한다(한 점에서 만난다).
15
포물선 $y=x^2$을 $x$축 방향으로 $2$, $y$축 방향으로 $-3$만큼 평행이동한 뒤 $x$축에 대하여 대칭이동한 포물선의 꼭짓점을 구하시오.
풀이
평행이동: $y=(x-2)^2-3$, 꼭짓점 $(2,-3)$
$x$축 대칭: $y$의 부호가 바뀌어 꼭짓점 $(2,3)$
