집합과 명제

공통수학2 · 집합 · 명제

한 줄로 외우기

집합은 "조건에 맞는 것들의 모임", 명제는 "참·거짓을 가릴 수 있는 문장"이다. 둘은 진리집합으로 이어진다: "p이면 q"가 참 ⇔ P ⊂ Q.

왜 배울까?수학의 정의와 정리는 모두 집합과 명제의 언어로 쓰인다. 확률의 사건, 함수의 정의역, 증명의 논리가 모두 여기서 나온다.

  • 명제

1집합

어떤 기준으로 대상을 분명하게 정할 수 있는 모임을 집합, 그 대상을 원소라 한다(a ∈ A). 원소를 늘어놓는 원소나열법 {1, 2, 3}과 조건을 쓰는 조건제시법 {x | x는 3 이하의 자연수}가 있다. 원소가 없는 집합은 공집합 ∅이다.

기호뜻
A ⊂ B부분집합: A의 원소가 모두 B에 속함
A ∪ B합집합: A 또는 B에 속함
A ∩ B교집합: A와 B에 모두 속함
AC여집합: 전체집합 U에서 A가 아닌 것
A − B차집합: A에는 있고 B에는 없음
예
A = {1, 2, 3, 4}, B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}, A ∩ B = {3, 4}, A − B = {1, 2}
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

원소가 n개인 집합의 부분집합은 2n개다(각 원소마다 넣을지 말지 2가지).

2명제

참인지 거짓인지 분명하게 판별할 수 있는 문장이나 식을 명제라 한다. "p이면 q이다"(p → q)에서 p를 가정, q를 결론이라 한다. 조건 p를 참으로 만드는 원소의 집합 P를 진리집합이라 하면, p → q가 참인 것은 P ⊂ Q인 것과 같다.

p → q 에 대하여
역q → p
이~p → ~q
대우~q → ~p
핵심
명제와 그 대우는 참·거짓이 항상 같다. 하지만 역은 다를 수 있다. 예: "x = 2이면 x2 = 4"는 참, 역 "x2 = 4이면 x = 2"는 거짓(x = −2).

p → q가 참일 때 p는 q이기 위한 충분조건, q는 p이기 위한 필요조건이다. 양쪽 다 참이면 필요충분조건(p ⇔ q).

어떤 실수를 넣어도 항상 성립하는 부등식을 절대부등식이라 한다. 대표적인 것이 산술평균과 기하평균의 관계다.

a + b2 ≥ √ab  (a > 0, b > 0, 등호는 a = b일 때)

꼭 외울 것

  • n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
  • 부분집합의 개수 = 2n
  • p → q 참 ⇔ P ⊂ Q
  • 명제와 대우는 참·거짓이 같다
  • p → q 참이면 p는 충분조건, q는 필요조건
  • (a + b)/2 ≥ √(ab)
