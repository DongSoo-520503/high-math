다항식

공통수학1 · 다항식의 연산 · 항등식과 나머지정리 · 인수분해

한 줄로 외우기

다항식은 문자로 된 식을 더하고 곱하고 나누는 기술이다. 나머지정리는 "x에 a를 넣으면 x − a로 나눈 나머지가 바로 나온다"는 지름길이다.

왜 배울까?중3 인수분해는 이차식까지였다. 고등학교에서는 삼차·사차식도 다루므로, 다항식의 나눗셈과 나머지정리로 인수를 찾는 방법이 필요하다. 이 단원은 방정식, 함수, 미적분의 모든 계산을 받치는 기본기다.

1다항식의 연산

식을 정리할 때는 차수가 높은 항부터 쓰는 내림차순이 기본이다. 덧셈·뺄셈은 동류항끼리 모으고, 곱셈은 분배법칙으로 펼친다. 중3 곱셈공식에 다음 공식들이 더해진다.

(a + b)3 = a3 + 3a2b + 3ab2 + b3
(a − b)3 = a3 − 3a2b + 3ab2 − b3
(a + b)(a2 − ab + b2) = a3 + b3
(a − b)(a2 + ab + b2) = a3 − b3
(a + b + c)2 = a2 + b2 + c2 + 2ab + 2bc + 2ca

다항식도 수처럼 나눌 수 있다. A를 B로 나눈 몫을 Q, 나머지를 R라 하면

A = BQ + R   (R의 차수 < B의 차수)
예
(x2 + 3x + 5) ÷ (x + 1) → 몫 x + 2, 나머지 3
확인: (x + 1)(x + 2) + 3 = x2 + 3x + 2 + 3 = x2 + 3x + 5

2항등식과 나머지정리

x에 어떤 값을 넣어도 항상 성립하는 등식을 항등식이라 한다. 예: (x + 1)2 = x2 + 2x + 1. 항등식이면 양변의 같은 차수 항의 계수가 같다(계수비교법). 또 아무 값이나 넣어도 되므로 편한 값을 넣어 계수를 구할 수 있다(수치대입법).

A = BQ + R에서 B가 x − a이면, x = a를 넣었을 때 B가 0이 되어 R만 남는다. 이것이 나머지정리다.

나머지정리다항식 P(x)를 x − a로 나눈 나머지는 P(a)
인수정리P(a) = 0 ⇔ P(x)는 x − a로 나누어떨어진다 (x − a가 인수)
예
P(x) = x3 − 2x + 4를 x − 2로 나눈 나머지 → P(2) = 8 − 4 + 4 = 8
직접 나눗셈을 하지 않아도 된다.

나눗셈을 계수만으로 빠르게 하는 방법이 조립제법이다. 교과서에서 x − a로 나눌 때 자주 쓴다.

3인수분해

곱셈공식을 거꾸로 쓰는 것이 인수분해다. 삼차식 공식 두 개가 새로 쓰인다.

a3 + b3 = (a + b)(a2 − ab + b2)
a3 − b3 = (a − b)(a2 + ab + b2)

공식으로 안 되는 삼차식은 인수정리를 쓴다. 상수항의 약수(±1, ±2, …)를 넣어 보아 P(a) = 0이 되는 a를 찾으면 x − a가 인수다.

P(x) = x3 − 6x2 + 11x − 6
P(1) = 1 − 6 + 11 − 6 = 0 → x − 1이 인수
= (x − 1)(x2 − 5x + 6) 조립제법으로 나눔
= (x − 1)(x − 2)(x − 3)

꼭 외울 것

  • A = BQ + R (나머지의 차수 < 나누는 식의 차수)
  • 나머지정리: P(x) ÷ (x − a)의 나머지 = P(a)
  • 인수정리: P(a) = 0이면 x − a가 인수
  • (a + b)3 = a3 + 3a2b + 3ab2 + b3
  • a3 ± b3 = (a ± b)(a2 ∓ ab + b2)
