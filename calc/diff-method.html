한 줄로 외우기

복잡한 함수는 규칙으로 쪼개서 미분한다. 합성함수는 "겉을 미분 × 속을 미분"(연쇄법칙)이 핵심이다.

왜 배울까?실제로 만나는 함수는 분수 꼴, 함수 속에 함수가 든 꼴, x와 y의 관계식 꼴로 나온다. 이들을 미분할 수 있어야 곡선의 접선, 그래프의 오목·볼록, 평면 위의 운동까지 다룰 수 있다.

1몫·합성함수의 미분

몫의 미분{f(x)g(x)}′ = f′(x)g(x) − f(x)g′(x){g(x)}2
합성함수의 미분 (연쇄법칙){f(g(x))}′ = f′(g(x)) · g′(x)
실수 n(xn)′ = nxn−1
예
{(2x + 1)5}′ = 5(2x + 1)4 × 2 = 10(2x + 1)4
(ex2)′ = ex2 × 2x
(tan x)′ = (sin x / cos x)′ = 1/cos2x = sec2x

2매개변수·음함수·역함수의 미분

매개변수 x = f(t), y = g(t)dydx = dy/dtdx/dt
음함수 (x, y가 섞인 식)양변을 x로 미분, y는 y의 함수로 보고 연쇄법칙
역함수dydx = 1dx/dy
음함수
원 x2 + y2 = 1 → 2x + 2y · y′ = 0 → y′ = −xy

도함수를 한 번 더 미분한 것을 이계도함수 f″(x)라 한다.

3도함수의 활용

접선y − f(a) = f′(a)(x − a)
증가·감소, 극값f′의 부호로 판단 (미적분Ⅰ과 같음)
오목·볼록f″ > 0이면 아래로 볼록, f″ < 0이면 위로 볼록
변곡점f″의 부호가 바뀌는 점
평면 운동속도 (dx/dt, dy/dt), 속력 √((dx/dt)2 + (dy/dt)2)

꼭 외울 것

  • (f/g)′ = (f′g − fg′)/g²
  • 연쇄법칙: {f(g(x))}′ = f′(g(x))g′(x)
  • 매개변수: dy/dx = (dy/dt)/(dx/dt)
  • 음함수: y를 포함한 채로 양변 미분
  • f″ > 0 아래로 볼록, 부호 바뀌면 변곡점
