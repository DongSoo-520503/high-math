한 줄로 외우기

미분 공식을 거꾸로 읽으면 적분 공식이다. 바로 안 되면 치환적분(속을 t로 바꾸기)이나 부분적분(곱의 미분을 거꾸로)을 쓴다.

왜 배울까?지수·로그·삼각함수가 들어간 넓이, 부피, 누적량을 구하려면 이 함수들을 적분할 수 있어야 한다.

  • 여러 가지 함수의 적분
  • 치환적분법
  • 부분적분법

1여러 가지 함수의 적분

∫xndx = xn+1n + 1 + C (n ≠ −1)∫1xdx = ln|x| + C
∫exdx = ex + C∫axdx = axln a + C
∫sin x dx = −cos x + C∫cos x dx = sin x + C
∫sec2x dx = tan x + C
예
∫0π sin x dx = [−cos x]0π = 1 + 1 = 2

2치환적분법

식 안에 "어떤 함수와 그 도함수"가 함께 있으면 그 함수를 t로 바꾼다.

∫f(g(x))g′(x)dx = ∫f(t)dt  (t = g(x))
∫2x(x2 + 1)3dx
t = x2 + 1로 놓으면 dt = 2x dx
= ∫t3dt = t4/4 + C = (x2 + 1)4/4 + C

특히 ∫f′(x)f(x)dx = ln|f(x)| + C는 자주 쓰인다.

주의
정적분에서 치환하면 적분 구간도 t의 값으로 바꿔야 한다.

3부분적분법

곱의 미분 (fg)′ = f′g + fg′를 거꾸로 쓴 것이다.

∫f(x)g′(x)dx = f(x)g(x) − ∫f′(x)g(x)dx
예
∫x exdx: f = x, g′ = ex → x ex − ∫exdx = (x − 1)ex + C
∫ln x dx: f = ln x, g′ = 1 → x ln x − x + C

미분할 쪽(f)은 로그 → 다항 → 삼각 → 지수 순서로 고르면 대개 쉬워진다("로다삼지").

꼭 외울 것

  • ∫1/x dx = ln|x| + C
  • ∫exdx = ex + C
  • ∫sin x = −cos x, ∫cos x = sin x
  • 치환: 속 함수를 t로, 구간도 바꿈
  • 부분적분: ∫fg′ = fg − ∫f′g
