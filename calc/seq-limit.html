수열의 극한

Ⅰ 수열의 극한 · 수열의 수렴과 발산 · 극한의 성질 · 등비수열의 극한

한 줄로 외우기

n이 한없이 커질 때 수열이 어떤 값에 다가가면 수렴, 그렇지 않으면 발산이다. 등비수열 rn은 −1 < r < 1일 때 0으로 다가간다.

왜 배울까?미적분Ⅰ의 함수의 극한을 수열에서 다시 다룬다. 끝없이 더하는 급수, 원주율이나 e 같은 수를 정확히 정의하려면 수열의 극한이 필요하다.

1수열의 수렴과 발산

n이 한없이 커질 때 an이 일정한 값 α에 한없이 가까워지면 수열이 α에 수렴한다고 하고 limn→∞ an = α로 쓴다. 수렴하지 않으면 발산이다.

종류예
수렴1/n → 0,  3 − 1/n → 3
양의 무한대로 발산n2 → ∞
음의 무한대로 발산−2n → −∞
진동(−1)n: −1, 1, −1, 1, …

2극한의 성질

수렴하는 두 수열은 극한끼리 더하고 빼고 곱하고 나눌 수 있다. 꼴이 정해지지 않은 극한은 다음처럼 바꿔서 구한다.

∞/∞
lim 3n2 + 1n2 + n → 분모의 최고차항 n2으로 나누면 3 + 1/n21 + 1/n → 3
∞ − ∞
lim (√(n2 + n) − n) = lim n√(n2 + n) + n = lim 1√(1 + 1/n) + 1 = 1/2

an ≤ cn ≤ bn이고 an과 bn이 같은 값 α에 수렴하면 cn도 α에 수렴한다(샌드위치 원리).

3등비수열의 극한

공비 rrn의 극한
r > 1∞로 발산
r = 11에 수렴
−1 < r < 10에 수렴
r ≤ −1진동(발산)

그래서 rn이 수렴할 조건은 −1 < r ≤ 1이다. 여러 등비수열이 섞여 있으면 밑이 가장 큰 것으로 분모와 분자를 나눈다.

예
lim 2n + 3n+13n − 1 → 3n으로 나누면 (2/3)n + 31 − (1/3)n → 3

꼭 외울 것

  • 수렴: 한 값에 다가감 / 발산: ∞, −∞, 진동
  • ∞/∞ → 분모의 최고차항으로 나눔
  • ∞ − ∞ (√ 포함) → 유리화
  • rn은 −1 < r < 1이면 0
  • 여러 등비 → 밑이 가장 큰 것으로 나눔

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$\displaystyle\lim_{n\to\infty}\dfrac{2n+1}{n-3}$의 값을 구하시오.
풀이
분모·분자를 $n$으로 나누면 $\dfrac{2+\frac1n}{1-\frac3n}\to2$
2
$\displaystyle\lim_{n\to\infty}\dfrac{n^2+1}{2n^2+n}$의 값을 구하시오.
풀이
최고차항의 계수비 $\dfrac12$
3
$\displaystyle\lim_{n\to\infty}(\sqrt{n^2+2n}-n)$의 값을 구하시오.
풀이
유리화: $\dfrac{2n}{\sqrt{n^2+2n}+n}=\dfrac{2}{\sqrt{1+\frac2n}+1}\to1$
4
$\displaystyle\lim_{n\to\infty}\dfrac{3^{n+1}+2^n}{3^n-2^n}$의 값을 구하시오.
풀이
분모·분자를 $3^n$으로 나누면 $\dfrac{3+(\frac23)^n}{1-(\frac23)^n}\to3$
5
$\displaystyle\lim_{n\to\infty}\left\{\left(\dfrac23\right)^n+1\right\}$의 값을 구하시오.
풀이
$|r|\lt1$이면 $r^n\to0$ → $0+1=1$

교과서 응용6–10번

6
등비수열 $\{(x-1)^n\}$이 수렴하도록 하는 실수 $x$의 값의 범위를 구하시오.
풀이
$\{r^n\}$이 수렴 ⇔ $-1\lt r\le1$
$-1\lt x-1\le1$ → $0\lt x\le2$
7
$\displaystyle\lim_{n\to\infty}(2n+1)a_n=4$일 때 $\displaystyle\lim_{n\to\infty}na_n$의 값을 구하시오.
풀이
$na_n=(2n+1)a_n\times\dfrac{n}{2n+1}\to4\times\dfrac12=2$
8
$\displaystyle\lim_{n\to\infty}\dfrac{1+2+3+\cdots+n}{n^2}$의 값을 구하시오.
풀이
$\dfrac{n(n+1)/2}{n^2}\to\dfrac12$
9
$\displaystyle\lim_{n\to\infty}\sqrt n\,(\sqrt{n+1}-\sqrt n)$의 값을 구하시오.
풀이
$\dfrac{\sqrt n}{\sqrt{n+1}+\sqrt n}=\dfrac{1}{\sqrt{1+\frac1n}+1}\to\dfrac12$
10
$\displaystyle\lim_{n\to\infty}\dfrac{2^{n+1}+3^n}{2^n+3^{n+1}}$의 값을 구하시오.
풀이
$3^n$으로 나누면 $\dfrac{2(\frac23)^n+1}{(\frac23)^n+3}\to\dfrac13$

내신·수능 심화11–15번

11
$f(x)=\displaystyle\lim_{n\to\infty}\dfrac{x^{2n+1}+1}{x^{2n}+1}$일 때 $f(2)+f(1)+f\!\left(\dfrac12\right)$의 값을 구하시오.
풀이
$|x|\gt1$: $\dfrac{x+x^{-2n}}{1+x^{-2n}}\to x$ → $f(2)=2$
$x=1$: $\dfrac22=1$, $|x|\lt1$: $\dfrac{0+1}{0+1}=1$ → 합 $4$
12
$\displaystyle\lim_{n\to\infty}\dfrac{an^2+bn+1}{2n+1}=3$일 때 $a+b$의 값을 구하시오.
풀이
수렴하려면 $a=0$, 그때 극한 $\dfrac b2=3$ → $b=6$ → $a+b=6$
13
모든 자연수 $n$에 대하여 $2n-1\lt a_n\lt2n+3$일 때 $\displaystyle\lim_{n\to\infty}\dfrac{a_n}{n}$의 값을 구하시오.
풀이
$\dfrac{2n-1}n\lt\dfrac{a_n}n\lt\dfrac{2n+3}n$, 양쪽 모두 $2$로 수렴 → 샌드위치 정리로 $2$
14
$a_1=1,\ a_{n+1}=\dfrac12a_n+1$인 수열이 수렴할 때 그 극한값을 구하시오.
풀이
극한값을 $\alpha$라 하면 $\alpha=\dfrac12\alpha+1$ → $\alpha=2$
(실제로 $a_n=2-(\frac12)^{n-1}$)
15
수열 $\{(x^2)^n\}$이 수렴하도록 하는 정수 $x$의 개수를 구하시오.
풀이
공비 $x^2\ge0$, 수렴 조건 $x^2\le1$ → $x=-1,0,1$ → $3$개
