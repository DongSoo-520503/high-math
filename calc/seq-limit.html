수열의 극한

Ⅰ 수열의 극한 · 수열의 수렴과 발산 · 극한의 성질 · 등비수열의 극한

한 줄로 외우기

n이 한없이 커질 때 수열이 어떤 값에 다가가면 수렴, 그렇지 않으면 발산이다. 등비수열 rn은 −1 < r < 1일 때 0으로 다가간다.

왜 배울까?미적분Ⅰ의 함수의 극한을 수열에서 다시 다룬다. 끝없이 더하는 급수, 원주율이나 e 같은 수를 정확히 정의하려면 수열의 극한이 필요하다.

1수열의 수렴과 발산

n이 한없이 커질 때 an이 일정한 값 α에 한없이 가까워지면 수열이 α에 수렴한다고 하고 limn→∞ an = α로 쓴다. 수렴하지 않으면 발산이다.

종류예
수렴1/n → 0,  3 − 1/n → 3
양의 무한대로 발산n2 → ∞
음의 무한대로 발산−2n → −∞
진동(−1)n: −1, 1, −1, 1, …

2극한의 성질

수렴하는 두 수열은 극한끼리 더하고 빼고 곱하고 나눌 수 있다. 꼴이 정해지지 않은 극한은 다음처럼 바꿔서 구한다.

∞/∞
lim 3n2 + 1n2 + n → 분모의 최고차항 n2으로 나누면 3 + 1/n21 + 1/n → 3
∞ − ∞
lim (√(n2 + n) − n) = lim n√(n2 + n) + n = lim 1√(1 + 1/n) + 1 = 1/2

an ≤ cn ≤ bn이고 an과 bn이 같은 값 α에 수렴하면 cn도 α에 수렴한다(샌드위치 원리).

3등비수열의 극한

공비 rrn의 극한
r > 1∞로 발산
r = 11에 수렴
−1 < r < 10에 수렴
r ≤ −1진동(발산)

그래서 rn이 수렴할 조건은 −1 < r ≤ 1이다. 여러 등비수열이 섞여 있으면 밑이 가장 큰 것으로 분모와 분자를 나눈다.

예
lim 2n + 3n+13n − 1 → 3n으로 나누면 (2/3)n + 31 − (1/3)n → 3

꼭 외울 것

  • 수렴: 한 값에 다가감 / 발산: ∞, −∞, 진동
  • ∞/∞ → 분모의 최고차항으로 나눔
  • ∞ − ∞ (√ 포함) → 유리화
  • rn은 −1 < r < 1이면 0
  • 여러 등비 → 밑이 가장 큰 것으로 나눔

확인 문제

1lim 2n + 54n − 1은?답 보기
1/2
2lim (0.9)n은?답 보기
−1 < 0.9 < 1 → 0
3lim 5n + 2n5n+1은?답 보기
5n으로 나누면 (1 + (2/5)n)/5 → 1/5
