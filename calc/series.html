급수

Ⅰ 수열의 극한 · 급수의 수렴과 발산 · 등비급수

한 줄로 외우기

급수는 수열을 끝없이 더한 것으로, 부분합 Sn의 극한으로 정한다. 등비급수는 −1 < r < 1일 때 a/(1 − r)로 수렴한다.

왜 배울까?0.999…가 왜 1과 같은지, 끝없이 반씩 잘라 더해도 왜 유한한지를 설명한다. 중2에서 순환소수를 분수로 바꾼 원리가 바로 등비급수다.

  • 등비급수
  • 연습문제 15

1급수의 수렴과 발산

a1 + a2 + a3 + … = Σn=1∞ an을 급수라 한다. 첫째항부터 제n항까지의 합 Sn(부분합)이 S에 수렴하면 급수의 합이 S다.

예
Σ 1n(n + 1) = Σ(1n − 1n + 1) → Sn = 1 − 1n + 1 → 1
Σan이 수렴하면 lim an = 0  →  lim an ≠ 0이면 Σan은 발산
주의
거꾸로는 성립하지 않는다. 1 + 1/2 + 1/3 + 1/4 + …은 각 항이 0으로 가지만 합은 무한히 커진다(발산).

2등비급수

첫째항 a, 공비 r인 등비급수는

Σn=1∞ arn−1 = a1 − r  (−1 < r < 1, a ≠ 0)

부분합 Sn = a(1 − rn)/(1 − r)에서 rn → 0이기 때문이다. |r| ≥ 1이면 발산한다.

예
1 + 1/2 + 1/4 + … = 1/(1 − 1/2) = 2
0.333… = 3/10 + 3/100 + … = (3/10)/(1 − 1/10) = 1/3,  0.999… = (9/10)/(1 − 1/10) = 1

닮은 도형을 끝없이 그려 넓이나 둘레를 더하는 문제도 닮음비가 공비인 등비급수로 푼다.

꼭 외울 것

  • 급수의 합 = lim Sn
  • Σan 수렴 ⇒ an → 0 (역은 거짓)
  • 등비급수 = a/(1 − r), −1 < r < 1
  • 순환소수 = 등비급수

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$\displaystyle\sum_{n=1}^{\infty}\left(\dfrac12\right)^n$의 값을 구하시오.
풀이
첫째항 $\dfrac12$, 공비 $\dfrac12$ → $\dfrac{1/2}{1-1/2}=1$
2
$\displaystyle\sum_{n=1}^{\infty}3\left(\dfrac23\right)^{n-1}$의 값을 구하시오.
풀이
$\dfrac{3}{1-\frac23}=9$
3
$\displaystyle\sum_{n=1}^{\infty}\dfrac1{n(n+1)}$의 값을 구하시오.
풀이
부분합 $S_n=1-\dfrac1{n+1}\to1$
4
순환소수 $0.\dot1\dot2$를 분수로 나타내시오.
풀이
$0.12+0.0012+\cdots=\dfrac{0.12}{1-0.01}=\dfrac{12}{99}=\dfrac4{33}$
5
$\displaystyle\sum_{n=1}^{\infty}\left(-\dfrac13\right)^n$의 값을 구하시오.
풀이
$\dfrac{-\frac13}{1+\frac13}=-\dfrac14$

교과서 응용6–10번

6
급수 $\displaystyle\sum_{n=1}^{\infty}(a_n-3)$이 수렴할 때 $\displaystyle\lim_{n\to\infty}\dfrac{2a_n+1}{a_n-1}$의 값을 구하시오.
풀이
급수가 수렴하면 일반항 → 0: $a_n\to3$
$\dfrac{7}{2}$
7
등비급수 $\displaystyle\sum_{n=1}^{\infty}(x-1)^n$이 수렴하도록 하는 $x$의 값의 범위를 구하시오.
풀이
등비급수 수렴 ⇔ $|r|\lt1$ (첫째항이 0이 아닐 때) → $0\lt x\lt2$
(등비수열의 수렴 조건 $-1\lt r\le1$과 다름에 주의)
8
$\displaystyle\sum_{n=1}^{\infty}\dfrac{1}{(2n-1)(2n+1)}$의 값을 구하시오.
풀이
$\dfrac12\left(\dfrac1{2n-1}-\dfrac1{2n+1}\right)$ → $\dfrac12\cdot1=\dfrac12$
9
공을 10 m 높이에서 떨어뜨리면 떨어진 높이의 $\dfrac35$만큼 튀어 오르기를 한없이 반복한다. 공이 움직인 거리의 총합을 구하시오.
풀이
처음 낙하 10, 이후 오르내림이 $2\times(6+\frac{18}5+\cdots)$
$10+2\cdot\dfrac{6}{1-\frac35}=10+30=40$ (m)
10
$\displaystyle\sum_{n=1}^{\infty}\dfrac{2^n+3^n}{6^n}$의 값을 구하시오.
풀이
$\sum\left(\frac13\right)^n+\sum\left(\frac12\right)^n=\dfrac12+1=\dfrac32$

내신·수능 심화11–15번

11
넓이가 1인 정사각형의 각 변의 중점을 이어 새 정사각형을 만드는 과정을 한없이 반복할 때, 처음 것을 포함한 모든 정사각형의 넓이의 합을 구하시오.
풀이
넓이가 매번 $\dfrac12$배 → $\dfrac{1}{1-\frac12}=2$
12
$\displaystyle\lim_{n\to\infty}a_n=0$이면 $\displaystyle\sum a_n$은 항상 수렴하는가? $a_n=\dfrac{1}{\sqrt{n+1}+\sqrt n}$의 예로 판단하시오.
풀이
$a_n=\sqrt{n+1}-\sqrt n$, 부분합 $S_n=\sqrt{n+1}-1\to\infty$ → 발산
일반항 → 0은 수렴의 필요조건일 뿐 충분조건이 아니다.
13
급수의 부분합이 $S_n=\dfrac{2n}{n+1}$일 때 $a_5$와 $\displaystyle\sum_{n=1}^\infty a_n$을 구하시오.
풀이
$a_5=S_5-S_4=\dfrac{10}6-\dfrac85=\dfrac1{15}$
$\displaystyle\sum a_n=\lim S_n=2$
14
등비급수 $\displaystyle\sum_{n=1}^{\infty}ar^{n-1}=4$, $\displaystyle\sum_{n=1}^{\infty}a^2r^{2(n-1)}=8$일 때 $a$의 값을 구하시오.
풀이
$\dfrac{a}{1-r}=4,\ \dfrac{a^2}{1-r^2}=8$
나누면 $\dfrac{a}{1+r}=2$ → $4(1-r)=2(1+r)$ → $r=\dfrac13,\ a=\dfrac83$
15
$\displaystyle\sum_{n=1}^{\infty}\dfrac{n}{2^n}$의 값을 구하시오.
풀이
$S=\dfrac12+\dfrac2{4}+\dfrac3{8}+\cdots$, $\dfrac12S=\dfrac14+\dfrac2{8}+\cdots$
빼면 $\dfrac12S=\dfrac12+\dfrac14+\cdots=1$ → $S=2$
