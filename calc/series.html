급수

Ⅰ 수열의 극한 · 급수의 수렴과 발산 · 등비급수

한 줄로 외우기

급수는 수열을 끝없이 더한 것으로, 부분합 Sn의 극한으로 정한다. 등비급수는 −1 < r < 1일 때 a/(1 − r)로 수렴한다.

왜 배울까?0.999…가 왜 1과 같은지, 끝없이 반씩 잘라 더해도 왜 유한한지를 설명한다. 중2에서 순환소수를 분수로 바꾼 원리가 바로 등비급수다.

  • 급수의 수렴과 발산
  • 등비급수

1급수의 수렴과 발산

a1 + a2 + a3 + … = Σn=1∞ an을 급수라 한다. 첫째항부터 제n항까지의 합 Sn(부분합)이 S에 수렴하면 급수의 합이 S다.

예
Σ 1n(n + 1) = Σ(1n − 1n + 1) → Sn = 1 − 1n + 1 → 1
Σan이 수렴하면 lim an = 0  →  lim an ≠ 0이면 Σan은 발산
주의
거꾸로는 성립하지 않는다. 1 + 1/2 + 1/3 + 1/4 + …은 각 항이 0으로 가지만 합은 무한히 커진다(발산).

2등비급수

첫째항 a, 공비 r인 등비급수는

Σn=1∞ arn−1 = a1 − r  (−1 < r < 1, a ≠ 0)

부분합 Sn = a(1 − rn)/(1 − r)에서 rn → 0이기 때문이다. |r| ≥ 1이면 발산한다.

예
1 + 1/2 + 1/4 + … = 1/(1 − 1/2) = 2
0.333… = 3/10 + 3/100 + … = (3/10)/(1 − 1/10) = 1/3,  0.999… = (9/10)/(1 − 1/10) = 1

닮은 도형을 끝없이 그려 넓이나 둘레를 더하는 문제도 닮음비가 공비인 등비급수로 푼다.

꼭 외울 것

  • 급수의 합 = lim Sn
  • Σan 수렴 ⇒ an → 0 (역은 거짓)
  • 등비급수 = a/(1 − r), −1 < r < 1
  • 순환소수 = 등비급수

확인 문제

14 + 2 + 1 + 1/2 + …의 합은?답 보기
4/(1 − 1/2) = 8
2Σ(−1/3)n−1의 합은?답 보기
1/(1 + 1/3) = 3/4
3Σ nn + 1은 수렴하는가?답 보기
an → 1 ≠ 0이므로 발산
