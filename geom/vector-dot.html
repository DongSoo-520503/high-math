벡터의 내적과 도형

한 줄로 외우기

벡터를 성분 (a1, a2)로 쓰면 계산이 쉬워진다. 내적 a·b = |a||b|cos θ = a1b1 + a2b2 하나로 각도와 수직을 판단한다.

왜 배울까?두 방향 사이의 각, 두 직선이 수직인지, 한 방향으로 미는 힘이 한 일의 양을 계산한다. 직선과 원을 벡터로 나타내 두면 성분을 하나(z) 더 붙여 공간의 직선·평면·구까지 같은 방법으로 나타낼 수 있다.

1벡터의 성분

시작점을 원점 O로 놓은 벡터 OP를 점 P의 위치벡터라 한다. P(a1, a2)이면 a = (a1, a2)로 쓰고 이것을 성분이라 한다.

크기|a| = √a12 + a22
덧셈·실수배성분끼리 계산
AB(x2 − x1, y2 − y1)
m : n 내분점의 위치벡터mb + nam + n

2벡터의 내적

a·b = |a||b| cos θ = a1b1 + a2b2

내적의 결과는 벡터가 아니라 수다. 성분으로 계산한 뒤 크기로 나누면 사잇각을 얻는다.

사잇각cos θ = a·b|a||b|
수직a ⊥ b ⇔ a·b = 0
크기a·a = |a|2
예
a = (1, 1), b = (0, 2): 내적 2, |a| = √2, |b| = 2 → cos θ = 1/√2 → θ = 45°

3직선과 원의 방정식

방정식
점 A를 지나고 방향벡터 u = (u1, u2)x − x1u1 = y − y1u2
점 A를 지나고 법선벡터 n = (a, b)a(x − x1) + b(y − y1) = 0
중심 C, 반지름 r인 원|p − c| = r

방향벡터는 직선과 평행한 벡터, 법선벡터는 직선에 수직인 벡터다. 두 직선이 이루는 각은 방향벡터끼리의 각으로 구한다.

4공간벡터와 평면·구의 방정식

좌표공간에서는 성분이 하나 늘어 a = (a1, a2, a3)가 된다. 덧셈·실수배·내적 모두 평면에서 하던 계산에 z성분만 더 붙이면 된다.

식
크기|a| = √a12 + a22 + a32
내적a·b = a1b1 + a2b2 + a3b3 = |a||b|cos θ
직선 (점 A, 방향벡터 u)x − x1u1 = y − y1u2 = z − z1u3
평면 (점 A, 법선벡터 n = (a, b, c))a(x − x1) + b(y − y1) + c(z − z1) = 0
구 (중심 C, 반지름 r)|p − c| = r ⇔ (x − c1)2 + (y − c2)2 + (z − c3)2 = r2

평면의 방정식에서 x, y, z의 계수 (a, b, c)가 곧 법선벡터다. 그래서 두 평면이 이루는 각은 법선벡터끼리의 각으로, 직선이 평면에 수직인지는 방향벡터가 법선벡터와 평행한지로 판단한다.

예
점 (1, 2, 3)을 지나고 n = (2, −1, 1)에 수직인 평면 → 2(x − 1) − (y − 2) + (z − 3) = 0 → 2x − y + z = 3

꼭 외울 것

  • |a| = √(a₁² + a₂²)
  • a·b = |a||b|cos θ = a₁b₁ + a₂b₂
  • 수직 ⇔ 내적 0
  • cos θ = a·b / (|a||b|)
  • 직선: (x − x₁)/u₁ = (y − y₁)/u₂
  • 공간: 성분 하나 추가 (a₁, a₂, a₃)
  • 평면: a(x − x₁) + b(y − y₁) + c(z − z₁) = 0, 법선 (a, b, c)

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$\vec a=(2,3),\ \vec b=(1,-1)$일 때 $\vec a\cdot\vec b$를 구하시오.
풀이
$2\cdot1+3\cdot(-1)=-1$
2
$\vec a=(3,4)$의 크기를 구하시오.
풀이
$\sqrt{9+16}=5$
3
$\vec a=(1,2),\ \vec b=(2,k)$가 서로 수직일 때 $k$를 구하시오.
풀이
$\vec a\cdot\vec b=2+2k=0$ → $k=-1$
4
$\vec a=(1,2),\ \vec b=(3,k)$가 서로 평행할 때 $k$를 구하시오.
풀이
$\vec b=3\vec a$ → $k=6$
5
$|\vec a|=2,\ |\vec b|=3$이고 두 벡터가 이루는 각이 $60^\circ$일 때 $\vec a\cdot\vec b$를 구하시오.
풀이
$2\cdot3\cdot\cos60^\circ=3$

교과서 응용6–10번

6
$|\vec a|=2,\ |\vec b|=3,\ \vec a\cdot\vec b=3$일 때 $|\vec a+\vec b|$를 구하시오.
풀이
$|\vec a+\vec b|^2=4+2\cdot3+9=19$ → $\sqrt{19}$
7
$\vec a=(1,1),\ \vec b=(1,0)$이 이루는 각의 크기를 구하시오.
풀이
$\cos\theta=\dfrac{1}{\sqrt2\cdot1}$ → $45^\circ$
8
점 $(1,2)$를 지나고 방향벡터가 $(2,3)$인 직선의 방정식을 구하시오.
풀이
$\dfrac{x-1}{2}=\dfrac{y-2}{3}$
9
점 $(2,1)$을 지나고 법선벡터가 $(3,-1)$인 직선의 방정식을 구하시오.
풀이
$3(x-2)-(y-1)=0$ → $3x-y=5$
10
중심이 $C(1,2)$, 반지름이 3인 원을 벡터로 나타내고 좌표로 바꾸시오.
풀이
$|\vec p-\vec c|=3$ → $(x-1)^2+(y-2)^2=9$

내신·수능 심화11–15번

11
$|\vec a|=|\vec b|=1,\ |\vec a-\vec b|=1$일 때 $|2\vec a+\vec b|$를 구하시오.
풀이
$|\vec a-\vec b|^2=2-2\vec a\cdot\vec b=1$ → $\vec a\cdot\vec b=\dfrac12$
$|2\vec a+\vec b|^2=4+2\cdot2\cdot\dfrac12+1=7$ → $\sqrt7$
12
한 변의 길이가 2인 정삼각형 $ABC$에서 $\vec{AB}\cdot\vec{AC}$를 구하시오.
풀이
$2\cdot2\cdot\cos60^\circ=2$
13
$|\vec a|=2,\ |\vec b|=1$이고 $2\vec a+\vec b$와 $\vec a-3\vec b$가 서로 수직일 때 두 벡터가 이루는 각의 크기를 구하시오.
풀이
$(2\vec a+\vec b)\cdot(\vec a-3\vec b)=2\cdot4-5\,\vec a\cdot\vec b-3=0$ → $\vec a\cdot\vec b=1$
$\cos\theta=\dfrac{1}{2\cdot1}=\dfrac12$ → $60^\circ$
14
$\vec a=(3,4)$일 때 $|\vec p-\vec a|=2$를 만족하는 점 $P$에 대하여 $|\vec p|$의 최댓값을 구하시오.
풀이
$P$는 중심 $(3,4)$, 반지름 2인 원 위 → 원점에서 중심까지 5 → 최댓값 $7$
15
두 직선 $\dfrac{x-1}2=y$와 $x=\dfrac{y+1}{3}$이 이루는 예각의 크기를 구하시오.
풀이
방향벡터 $(2,1),\ (1,3)$ → $\cos\theta=\dfrac{2+3}{\sqrt5\sqrt{10}}=\dfrac{1}{\sqrt2}$ → $45^\circ$

공간벡터 연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$\vec a=(1,2,2)$의 크기를 구하시오.
풀이
$\sqrt{1+4+4}=3$
2
$\vec a=(1,-2,3),\ \vec b=(2,1,1)$일 때 $\vec a\cdot\vec b$를 구하시오.
풀이
$2-2+3=3$
3
$\vec a=(2,k,1),\ \vec b=(1,2,-4)$가 서로 수직일 때 $k$를 구하시오.
풀이
$2+2k-4=0$ → $k=1$
4
두 점 $A(1,0,2),\ B(3,1,4)$에 대하여 $\vec{AB}$와 $|\vec{AB}|$를 구하시오.
풀이
$\vec{AB}=(2,1,2)$ (끝점 − 시작점), $|\vec{AB}|=\sqrt{4+1+4}=3$
5
점 $(1,2,3)$을 지나고 방향벡터가 $(2,-1,3)$인 직선의 방정식을 구하시오.
풀이
$\dfrac{x-1}{2}=\dfrac{y-2}{-1}=\dfrac{z-3}{3}$

교과서 응용6–10번

6
$\vec a=(1,1,0),\ \vec b=(1,0,1)$이 이루는 각의 크기를 구하시오.
풀이
$\cos\theta=\dfrac{1}{\sqrt2\cdot\sqrt2}=\dfrac12$ → $60^\circ$
7
점 $(2,-1,1)$을 지나고 법선벡터가 $(1,2,-2)$인 평면의 방정식을 구하시오.
풀이
$(x-2)+2(y+1)-2(z-1)=0$ → $x+2y-2z+2=0$
8
두 평면 $2x-y+2z=5,\ x+ky+z=1$이 서로 수직일 때 $k$를 구하시오.
풀이
두 평면이 수직 ⇔ 법선벡터가 수직
$(2,-1,2)\cdot(1,k,1)=2-k+2=0$ → $k=4$
9
두 점 $A(1,2,0),\ B(3,0,4)$를 지름의 양 끝으로 하는 구의 방정식을 구하시오.
풀이
구 위의 점 $P$는 $\vec{AP}\cdot\vec{BP}=0$ (지름의 원주각 $90^\circ$)
중심 $(2,1,2)$, 반지름 $\sqrt{1+1+4}=\sqrt6$ → $(x-2)^2+(y-1)^2+(z-2)^2=6$
10
직선 $\dfrac{x-1}{2}=\dfrac{y+1}{k}=\dfrac{z}{-1}$이 평면 $2x+y-z=3$에 수직일 때 $k$를 구하시오.
풀이
직선 ⊥ 평면 ⇔ 방향벡터 $\parallel$ 법선벡터
$(2,k,-1)\parallel(2,1,-1)$ → $k=1$

내신·수능 심화11–15번

11
원점에서 평면 $2x+y+2z=9$에 내린 수선의 발과 원점과 평면 사이의 거리를 구하시오.
풀이
수선은 법선 방향: $(2t,t,2t)$를 대입하면 $9t=9$ → $t=1$
수선의 발 $(2,1,2)$, 거리 $\sqrt{4+1+4}=3$
12
두 평면 $x+y=1,\ y+z=2$가 이루는 각의 크기를 구하시오.
풀이
법선벡터 $(1,1,0),\ (0,1,1)$ → $\cos\theta=\dfrac{1}{\sqrt2\sqrt2}=\dfrac12$ → $60^\circ$
13
구 $x^2+y^2+z^2=9$ 위의 점 $(1,2,2)$에서 구에 접하는 평면의 방정식을 구하시오.
풀이
접평면은 반지름 $\vec{OP}=(1,2,2)$에 수직 → 법선벡터 $(1,2,2)$
$(x-1)+2(y-2)+2(z-2)=0$ → $x+2y+2z=9$
14
직선 $x-1=\dfrac{y-2}{2}=\dfrac{z+1}{-2}$와 평면 $x+y+z=6$의 교점을 구하시오.
풀이
직선 위의 점 $(1+t,\ 2+2t,\ -1-2t)$를 대입: $2+t=6$ → $t=4$
교점 $(5,10,-9)$
15
세 점 $A(1,0,0),\ B(0,2,0),\ C(0,0,2)$를 지나는 평면의 방정식을 구하시오.
풀이
평면 $ax+by+cz=d$에 대입: $a=d,\ 2b=d,\ 2c=d$
$d=2$로 놓으면 $2x+y+z=2$ (법선벡터 $(2,1,1)$, $\vec{AB}\cdot(2,1,1)=-2+2=0$ 확인)
