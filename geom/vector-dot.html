한 줄로 외우기

벡터를 성분 (a1, a2)로 쓰면 계산이 쉬워진다. 내적 a·b = |a||b|cos θ = a1b1 + a2b2 하나로 각도와 수직을 판단한다.

왜 배울까?두 방향 사이의 각, 두 직선이 수직인지, 한 방향으로 미는 힘이 한 일의 양을 계산한다. 직선과 원을 벡터로 나타내 두면 공간으로 넓히기도 쉽다.

2벡터의 내적

a·b = |a||b| cos θ = a1b1 + a2b2

내적의 결과는 벡터가 아니라 수다. 성분으로 계산한 뒤 크기로 나누면 사잇각을 얻는다.

사잇각cos θ = a·b|a||b|
수직a ⊥ b ⇔ a·b = 0
크기a·a = |a|2
예
a = (1, 1), b = (0, 2): 내적 2, |a| = √2, |b| = 2 → cos θ = 1/√2 → θ = 45°

3직선과 원의 방정식

방정식
점 A를 지나고 방향벡터 u = (u1, u2)x − x1u1 = y − y1u2
점 A를 지나고 법선벡터 n = (a, b)a(x − x1) + b(y − y1) = 0
중심 C, 반지름 r인 원|p − c| = r

방향벡터는 직선과 평행한 벡터, 법선벡터는 직선에 수직인 벡터다. 두 직선이 이루는 각은 방향벡터끼리의 각으로 구한다.

꼭 외울 것

  • |a| = √(a₁² + a₂²)
  • a·b = |a||b|cos θ = a₁b₁ + a₂b₂
  • 수직 ⇔ 내적 0
  • cos θ = a·b / (|a||b|)
  • 직선: (x − x₁)/u₁ = (y − y₁)/u₂
