이차곡선의 접선

Ⅰ 이차곡선 · 포물선의 접선 · 타원의 접선 · 쌍곡선의 접선

한 줄로 외우기

이차곡선 위의 점 (x1, y1)에서의 접선은, 곡선의 식에서 x2을 x1x로, y2을 y1y로 바꾸면 바로 나온다.

왜 배울까?공통수학2에서 원의 접선을 판별식이나 수직 조건으로 구했다. 이차곡선도 같은 방법이 통하고, "접점의 좌표를 넣는" 공식으로 빠르게 구할 수 있다.

  • 타원의 접선
  • 쌍곡선의 접선

1포물선의 접선

접선 문제는 세 종류다. ① 곡선 위의 점이 주어질 때 ② 기울기가 주어질 때(y = mx + n을 대입해 판별식 D = 0) ③ 곡선 밖의 점이 주어질 때(접점을 (x1, y1)로 놓고 ①을 이용).

y² = 4px의 접선
점 (x1, y1)에서y1y = 2p(x + x1)
기울기 my = mx + pm

2타원의 접선

x²/a² + y²/b² = 1의 접선
점 (x1, y1)에서x1xa2 + y1yb2 = 1
기울기 my = mx ± √a2m2 + b2
예
x2/8 + y2/2 = 1 위의 점 (2, 1): 2x/8 + y/2 = 1 → x + 2y = 4

3쌍곡선의 접선

x²/a² − y²/b² = 1의 접선
점 (x1, y1)에서x1xa2 − y1yb2 = 1
기울기 my = mx ± √a2m2 − b2 (a2m2 > b2)
예
x2/4 − y2/3 = 1 위의 점 (4, 3): 4x/4 − 3y/3 = 1 → x − y = 1

이 공식들은 미적분Ⅱ의 음함수 미분으로도 똑같이 얻을 수 있다.

꼭 외울 것

  • 포물선: y₁y = 2p(x + x₁)
  • 타원: x₁x/a² + y₁y/b² = 1
  • 쌍곡선: x₁x/a² − y₁y/b² = 1
  • 기울기가 주어지면 대입 후 판별식 D = 0

확인 문제

1y2 = 8x 위의 점 (2, 4)에서의 접선은?답 보기
p = 2 → 4y = 4(x + 2) → y = x + 2
2x2/9 + y2/4 = 1 위의 점 (0, 2)에서의 접선은?답 보기
0 + 2y/4 = 1 → y = 2
3원 x2 + y2 = r2 위의 점 (x1, y1)에서의 접선은?답 보기
같은 규칙으로 x1x + y1y = r2
