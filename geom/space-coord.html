공간좌표

Ⅱ 공간도형과 공간좌표 · 두 점 사이의 거리 · 선분의 내분점 · 구의 방정식

한 줄로 외우기

평면좌표에 z축 하나를 더하면 공간의 점을 (x, y, z)로 나타낸다. 거리·내분점·원의 방정식이 모두 z 항 하나씩 늘어난 꼴이 된다.

왜 배울까?3차원 위치를 숫자로 다루는 방법이다. 게임, 드론, 건축 설계에서 쓰는 좌표가 바로 이것이다.

  • 두 점 사이의 거리
  • 선분의 내분점
  • 구의 방정식

1두 점 사이의 거리

서로 수직인 x축, y축, z축으로 공간의 점을 순서쌍 (x, y, z)로 나타낸다. 두 축이 정하는 평면을 xy평면, yz평면, zx평면이라 한다. 피타고라스 정리를 두 번 쓰면

AB = √(x2 − x1)2 + (y2 − y1)2 + (z2 − z1)2
예
(1, 2, 3)과 (3, 5, 9) → √(4 + 9 + 36) = √49 = 7

점 (x, y, z)를 xy평면에 대칭이동하면 (x, y, −z)처럼, 그 평면에 없는 좌표의 부호만 바뀐다.

2선분의 내분점

평면에서와 같은 공식에 z좌표만 더한다. m : n 내분점은

(mx2 + nx1m + n, my2 + ny1m + n, mz2 + nz1m + n)
예
A(1, 0, 2), B(4, 6, −1)을 2 : 1로 내분 → ((8 + 1)/3, 12/3, (−2 + 2)/3) = (3, 4, 0)

3구의 방정식

중심 (a, b, c)에서 거리가 r인 점들의 모임이 구다.

(x − a)2 + (y − b)2 + (z − c)2 = r2
예
x2 + y2 + z2 − 2x + 4y − 6z + 5 = 0
→ (x − 1)2 + (y + 2)2 + (z − 3)2 = 1 + 4 + 9 − 5 = 9 → 중심 (1, −2, 3), 반지름 3

구를 좌표평면으로 자르면 단면은 원이다. 예를 들어 xy평면과 만나는 부분은 z = 0을 넣어 구한다.

꼭 외울 것

  • 거리 = √(Δx² + Δy² + Δz²)
  • 내분점: 평면 공식 + z좌표
  • 구: (x − a)² + (y − b)² + (z − c)² = r²
  • xy평면 대칭: z의 부호만 바뀜
