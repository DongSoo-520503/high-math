미분

미적분Ⅰ · 미분계수와 도함수 · 도함수의 활용

한 줄로 외우기

미분은 "그 순간의 기울기(변화율)"를 구하는 계산이다. 다항함수는 (xn)′ = nxn−1 하나로 모두 미분된다.

왜 배울까?자동차 속도계의 숫자는 위치의 순간 변화율, 즉 미분값이다. 미분을 알면 그래프의 모양, 최댓값과 최솟값, 속도와 가속도를 계산할 수 있다.

1미분계수와 도함수

x가 a에서 b까지 변할 때의 평균변화율 (f(b) − f(a))/(b − a)는 두 점을 잇는 직선의 기울기다. 간격 h를 0에 한없이 가깝게 하면 한 점에서의 접선의 기울기, 곧 미분계수가 된다.

f′(a) = limh→0 f(a + h) − f(a)h

각 x에 미분계수 f′(x)를 대응시킨 함수를 도함수라 한다.

(xn)′ = nxn−1
(c)′ = 0 (상수)
{cf(x)}′ = cf′(x),  {f ± g}′ = f′ ± g′
{f(x)g(x)}′ = f′(x)g(x) + f(x)g′(x)
예
f(x) = x3 − 2x2 + 5 → f′(x) = 3x2 − 4x

2도함수의 활용

접선의 방정식y − f(a) = f′(a)(x − a)
증가·감소f′(x) > 0이면 증가, f′(x) < 0이면 감소
극대·극소f′(a) = 0이고 그 앞뒤에서 f′의 부호가 바뀌는 점
속도·가속도위치 x(t) → 속도 v = x′(t) → 가속도 a = v′(t)

방정식에의 활용 — 방정식 f(x) = k의 실근의 개수는 y = f(x)의 그래프와 직선 y = k의 교점 개수와 같다. 위 그래프라면 −2 < k < 2일 때 실근이 3개, k = ±2일 때 2개(중근 포함), |k| > 2일 때 1개다.

부등식에의 활용 — "어떤 범위의 모든 x에 대하여 f(x) ≥ g(x)"를 보이려면 h(x) = f(x) − g(x)로 놓고, 그 범위에서 h(x)의 최솟값이 0 이상임을 보이면 된다.

예
x ≥ 0일 때 x3 − 3x + 2 ≥ 0 증명
h(x) = x3 − 3x + 2, h′(x) = 3(x + 1)(x − 1) → x ≥ 0에서 x = 1일 때 최소
h(1) = 1 − 3 + 2 = 0 ≥ 0 이므로 성립 (등호는 x = 1)

꼭 외울 것

  • f′(a) = lim (f(a + h) − f(a))/h = 접선의 기울기
  • (xn)′ = nxn−1
  • 접선: y − f(a) = f′(a)(x − a)
  • f′의 부호가 바뀌는 점 → 극값
  • v = x′, a = v′
  • f(x) ≥ 0 증명 → 최솟값 ≥ 0

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$f(x)=x^3-2x+1$일 때 $f\,'(2)$의 값을 구하시오.
풀이
$f\,'(x)=3x^2-2$ → $f\,'(2)=10$
2
$f(x)=(2x+1)(x-3)$일 때 $f\,'(1)$의 값을 구하시오.
풀이
곱의 미분: $2(x-3)+(2x+1)$ → $f\,'(1)=-4+3=-1$
3
$f(x)=x^2$에서 $x$의 값이 1에서 3까지 변할 때 평균변화율을 구하시오.
풀이
$\dfrac{9-1}{3-1}=4$
4
곡선 $y=x^2$ 위의 점 $(1,1)$에서의 접선의 방정식을 구하시오.
풀이
기울기 $2\cdot1=2$ → $y-1=2(x-1)$ → $y=2x-1$
5
$f(x)=x^3$일 때 $\displaystyle\lim_{h\to0}\dfrac{f(1+2h)-f(1)}{h}$의 값을 구하시오.
풀이
$=2\cdot\displaystyle\lim\dfrac{f(1+2h)-f(1)}{2h}=2f\,'(1)=6$

교과서 응용6–10번

6
$f(x)=x^3-3x$의 극댓값과 극솟값을 구하시오.
풀이
$f\,'(x)=3(x+1)(x-1)$
$x=-1$에서 극댓값 $2$, $x=1$에서 극솟값 $-2$
7
$f(x)=x^3-6x^2+9x+1$이 감소하는 구간을 구하시오.
풀이
$f\,'(x)=3x^2-12x+9=3(x-1)(x-3)\le0$ → $[1,3]$
8
곡선 $y=x^3$ 위의 점 $(1,1)$에서의 접선이 $x$축과 만나는 점의 $x$좌표를 구하시오.
풀이
접선 $y=3(x-1)+1=3x-2$ → $x=\dfrac23$
9
수직선 위를 움직이는 점의 시각 $t$에서의 위치가 $x(t)=t^3-6t^2+9t$일 때 $t=2$에서의 속도를 구하시오.
풀이
$v(t)=3t^2-12t+9$ → $v(2)=12-24+9=-3$
10
구간 $[0,3]$에서 $f(x)=x^3-3x^2+1$의 최댓값과 최솟값을 구하시오.
풀이
$f\,'(x)=3x(x-2)$
$f(0)=1,\ f(2)=-3,\ f(3)=1$ → 최댓값 $1$, 최솟값 $-3$

내신·수능 심화11–15번

11
삼차방정식 $x^3-3x+k=0$이 서로 다른 세 실근을 갖도록 하는 $k$의 값의 범위를 구하시오.
풀이
$y=x^3-3x$와 $y=-k$가 세 점에서 만나야 한다
극댓값 $2$, 극솟값 $-2$ → $-2\lt-k\lt2$ → $-2\lt k\lt2$
12
$f(x)=x^3+ax^2+3x$가 실수 전체에서 증가하도록 하는 정수 $a$의 개수를 구하시오.
풀이
$f\,'(x)=3x^2+2ax+3\ge0$ → $\dfrac D4=a^2-9\le0$ → $-3\le a\le3$ → $7$개
13
점 $(0,-2)$에서 곡선 $y=x^2$에 그은 두 접선의 기울기의 곱을 구하시오.
풀이
접점 $(t,t^2)$에서 접선 $y=2tx-t^2$이 $(0,-2)$를 지나므로 $t^2=2$
기울기 $\pm2\sqrt2$ → 곱 $-8$
14
$x\ge0$인 모든 $x$에 대하여 $x^3-3x+k\ge0$이 성립하도록 하는 $k$의 최솟값을 구하시오.
풀이
$x\ge0$에서 $x^3-3x$의 최솟값은 $x=1$일 때 $-2$
$-2+k\ge0$ → $k\ge2$ → 최솟값 $2$
15
$f(x)=x^3-3x^2+a$의 극댓값과 극솟값의 합이 0일 때 $a$의 값을 구하시오.
풀이
$f\,'(x)=3x(x-2)$ → 극댓값 $f(0)=a$, 극솟값 $f(2)=a-4$
$2a-4=0$ → $a=2$
