함수의 극한과 연속

미적분Ⅰ · 함수의 극한 · 함수의 연속

한 줄로 외우기

극한은 "x가 a에 한없이 가까워질 때 f(x)가 다가가는 값"이다. 그 값이 실제 함숫값과 같으면 그래프가 끊기지 않는 연속이다.

왜 배울까?미분(순간의 변화율)은 "간격을 0에 한없이 가깝게"라는 극한 없이는 정의할 수 없다. 극한은 미적분으로 들어가는 문이다.

  • 함수의 연속

1함수의 극한

x가 a가 아니면서 a에 한없이 가까워질 때 f(x)가 L에 한없이 가까워지면 limx→a f(x) = L이라 쓴다. 왼쪽에서 다가갈 때(좌극한)와 오른쪽에서 다가갈 때(우극한)의 값이 같아야 극한이 존재한다.

0/0 꼴
limx→1 x2 − 1x − 1 = limx→1 (x − 1)(x + 1)x − 1 = limx→1 (x + 1) = 2
∞/∞ 꼴
limx→∞ 2x2 + 1x2 − 3 → 분모의 최고차항 x2으로 나누면 2 + 1/x21 − 3/x2 → 2

2함수의 연속

함수 f(x)가 x = a에서 연속이려면 세 가지가 모두 맞아야 한다.

① f(a)가 정의되어 있다
② limx→a f(x)가 존재한다
③ limx→a f(x) = f(a)

연속함수끼리 더하고 빼고 곱해도 연속이다. 닫힌구간 [a, b]에서 연속인 함수에는 두 가지 중요한 성질이 있다.

최대·최소 정리[a, b]에서 반드시 최댓값과 최솟값을 가진다
사잇값 정리f(a)와 f(b)의 부호가 다르면 a와 b 사이에 f(c) = 0인 c가 있다
예
x3 + x − 1 = 0: f(0) = −1 < 0, f(1) = 1 > 0 → 0과 1 사이에 근이 적어도 하나 있다

꼭 외울 것

  • 좌극한 = 우극한일 때 극한 존재
  • 0/0 꼴 → 인수분해 후 약분
  • ∞/∞ 꼴 → 분모의 최고차항으로 나눔
  • 연속: 함숫값 = 극한값
  • 사잇값 정리: 부호가 바뀌면 사이에 근

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$\displaystyle\lim_{x\to2}(x^2+3x)$의 값을 구하시오.
풀이
다항함수는 그대로 대입: $4+6=10$
2
$\displaystyle\lim_{x\to1}\dfrac{x^2-1}{x-1}$의 값을 구하시오.
풀이
$\dfrac{(x-1)(x+1)}{x-1}=x+1$ → $2$
3
$\displaystyle\lim_{x\to\infty}\dfrac{3x^2+1}{x^2-2}$의 값을 구하시오.
풀이
최고차항의 계수비 $\dfrac31=3$
4
$\displaystyle\lim_{x\to0}\dfrac{|x|}{x}$가 존재하는지 판단하시오.
풀이
우극한 $1$, 좌극한 $-1$로 서로 다르므로 극한이 존재하지 않는다.
5
$\displaystyle\lim_{x\to\infty}(\sqrt{x^2+x}-x)$의 값을 구하시오.
풀이
유리화: $\dfrac{x}{\sqrt{x^2+x}+x}=\dfrac{1}{\sqrt{1+\frac1x}+1}\to\dfrac12$

교과서 응용6–10번

6
$\displaystyle\lim_{x\to2}\dfrac{x^2+ax+b}{x-2}=5$일 때 $a+b$의 값을 구하시오.
풀이
분모 → 0이므로 분자 → 0: $4+2a+b=0$
분자 $=(x-2)(x+a+2)$ → 극한값 $4+a=5$ → $a=1,\ b=-6$ → $a+b=-5$
7
함수 $f(x)=\begin{cases}x^2+a&(x\lt1)\\2x+1&(x\ge1)\end{cases}$가 $x=1$에서 연속일 때 $a$의 값을 구하시오.
풀이
좌극한 $1+a$ = 함숫값 $3$ → $a=2$
8
$\displaystyle\lim_{x\to3}\dfrac{\sqrt{x+1}-2}{x-3}$의 값을 구하시오.
풀이
유리화: $\dfrac{x-3}{(x-3)(\sqrt{x+1}+2)}=\dfrac1{\sqrt{x+1}+2}\to\dfrac14$
9
$\displaystyle\lim_{x\to-\infty}\dfrac{2x+1}{\sqrt{x^2+1}}$의 값을 구하시오.
풀이
$x\lt0$이면 $\sqrt{x^2}=-x$ → $\dfrac{2+\frac1x}{-\sqrt{1+\frac1{x^2}}}\to-2$
10
방정식 $x^3+x-1=0$이 실근을 갖는 구간을 다음 중에서 고르시오. ① $(-1,0)$ ② $(0,1)$ ③ $(1,2)$
풀이
$f(x)=x^3+x-1$은 연속, $f(0)=-1\lt0,\ f(1)=1\gt0$
사잇값 정리 → ② $(0,1)$

내신·수능 심화11–15번

11
$f(x)=x^2+ax+b$에 대하여 $\displaystyle\lim_{x\to1}\dfrac{f(x)}{x-1}=3$일 때 $f(2)$의 값을 구하시오.
풀이
$f(1)=0$이므로 $f(x)=(x-1)(x-c)$, 극한값 $1-c=3$ → $c=-2$
$f(x)=(x-1)(x+2)$ → $f(2)=4$
12
다항함수 $f(x)$가 $\displaystyle\lim_{x\to\infty}\dfrac{f(x)}{x^2}=2,\ \lim_{x\to0}\dfrac{f(x)}{x}=3$을 만족할 때 $f(1)$의 값을 구하시오.
풀이
첫 조건: 이차, 최고차 계수 2 → $f(x)=2x^2+px+q$
둘째 조건: $q=0,\ p=3$ → $f(x)=2x^2+3x$, $f(1)=5$
13
$\displaystyle\lim_{x\to0}\dfrac{x}{\sqrt{1+x}-1}$의 값을 구하시오.
풀이
유리화: $\dfrac{x(\sqrt{1+x}+1)}{x}=\sqrt{1+x}+1\to2$
14
$f(x)=\dfrac{x^2-4}{x-2}\ (x\ne2),\ f(2)=k$가 $x=2$에서 연속일 때 $k$의 값을 구하시오.
풀이
$\displaystyle\lim_{x\to2}(x+2)=4=f(2)$ → $k=4$
15
$\displaystyle\lim_{x\to\infty}x(\sqrt{x^2+2}-x)$의 값을 구하시오.
풀이
$\dfrac{2x}{\sqrt{x^2+2}+x}=\dfrac{2}{\sqrt{1+\frac2{x^2}}+1}\to1$
