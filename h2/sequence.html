한 줄로 외우기

일정하게 더해 가면 등차수열, 일정하게 곱해 가면 등비수열이다. Σ는 "모두 더하라"는 기호이고, 수학적 귀납법은 도미노처럼 증명한다.

왜 배울까?적금·대출 이자, 매년 일정하게 늘어나는 양처럼 규칙적으로 변하는 것을 다룬다. 미적분Ⅱ의 수열의 극한과 급수, 적분의 구분구적법이 수열 위에 세워진다.

1등차수열과 등비수열

일반항첫째항부터 제n항까지의 합
등차수열 (공차 d)an = a + (n − 1)dSn = n{2a + (n − 1)d}2 = n(a + l)2
등비수열 (공비 r)an = arn−1Sn = a(rn − 1)r − 1 (r ≠ 1)
예
3, 7, 11, … (a = 3, d = 4): a10 = 3 + 9 × 4 = 39, S10 = 10(3 + 39)/2 = 210
2, 6, 18, … (a = 2, r = 3): a5 = 2 × 34 = 162, S5 = 2(35 − 1)/(3 − 1) = 242

l은 끝항이다. 등차수열의 합은 "처음 + 끝"을 짝지어 더하는 가우스의 방법에서 나온다.

2수열의 합

a1 + a2 + … + an을 기호 Σ(시그마)로 줄여 쓴다: Σk=1n ak. Σ는 더하기이므로 Σ(ak + bk) = Σak + Σbk, Σcak = cΣak, Σc = cn이 성립한다.

Σ k = n(n + 1)2
Σ k2 = n(n + 1)(2n + 1)6
Σ k3 = {n(n + 1)2}2
예
Σk=110 (2k + 1) = 2 × 55 + 10 = 120
주의
Σ(akbk)는 Σak × Σbk가 아니다. 곱은 Σ 밖으로 나누어 꺼낼 수 없다.

3수학적 귀납법

모든 자연수 n에 대해 성립함을 보이려면 두 가지만 확인하면 된다.

① n = 1일 때 성립한다. 첫 도미노가 쓰러진다
② n = k일 때 성립하면 n = k + 1일 때도 성립한다. 하나가 쓰러지면 다음 것도 쓰러진다
증명
1 + 3 + 5 + … + (2n − 1) = n2
① n = 1: 1 = 12 ✓
② k2 + (2k + 1) = (k + 1)2 ✓ → 모든 자연수에서 성립

a1 = 1, an+1 = an + 2처럼 첫째항과 앞뒤 항의 관계로 수열을 정하는 방법을 귀납적 정의라 한다.

꼭 외울 것

  • 등차: an = a + (n − 1)d, Sn = n(a + l)/2
  • 등비: an = arn−1, Sn = a(rn − 1)/(r − 1)
  • Σk = n(n + 1)/2
  • Σk² = n(n + 1)(2n + 1)/6
  • 귀납법: n = 1 확인 → k이면 k + 1

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
첫째항이 3, 공차가 4인 등차수열의 제10항을 구하시오.
풀이
$a_{10}=3+9\times4=39$
2
등비수열 $2,\ 6,\ 18,\ \cdots$의 제6항을 구하시오.
풀이
$a_6=2\times3^5=486$
3
$\displaystyle\sum_{k=1}^{10}(2k+1)$의 값을 구하시오.
풀이
$2\times\dfrac{10\cdot11}2+10=110+10=120$
4
$\displaystyle\sum_{k=1}^{10}k^2$의 값을 구하시오.
풀이
$\dfrac{10\cdot11\cdot21}{6}=385$
5
첫째항이 2, 공차가 3인 등차수열의 첫째항부터 제20항까지의 합을 구하시오.
풀이
$a_{20}=2+57=59$, $S_{20}=\dfrac{20(2+59)}2=610$

교과서 응용6–10번

6
등차수열에서 $a_3=7,\ a_7=19$일 때 $a_{20}$을 구하시오.
풀이
$4d=12$ → $d=3$, $a_1=1$ → $a_{20}=1+19\times3=58$
7
등비수열에서 $a_2=6,\ a_5=48$일 때 첫째항부터 제6항까지의 합을 구하시오.
풀이
$r^3=8$ → $r=2$, $a_1=3$
$S_6=\dfrac{3(2^6-1)}{2-1}=189$
8
$\displaystyle\sum_{k=1}^{20}\dfrac{1}{k(k+1)}$의 값을 구하시오.
풀이
$\dfrac1{k(k+1)}=\dfrac1k-\dfrac1{k+1}$ → 중간이 모두 지워져 $1-\dfrac1{21}=\dfrac{20}{21}$
9
$a_1=1,\ a_{n+1}=2a_n+1$로 정의된 수열의 제10항을 구하시오.
풀이
$a_{n+1}+1=2(a_n+1)$ → $a_n+1=2^n$ → $a_n=2^n-1$
$a_{10}=1023$
10
수열 $1,\ 2,\ 5,\ 10,\ 17,\ \cdots$의 제10항을 구하시오.
풀이
계차 $1,3,5,7,\cdots$ (홀수) → $a_n=1+\displaystyle\sum_{k=1}^{n-1}(2k-1)=1+(n-1)^2$
$a_{10}=82$

내신·수능 심화11–15번

11
수열 $\{a_n\}$의 첫째항부터 제$n$항까지의 합이 $S_n=n^2+2n$일 때 $a_{10}$을 구하시오.
풀이
$a_{10}=S_{10}-S_9=120-99=21$
12
$S_n=n^2+n+1$일 때 $a_1+a_{10}$의 값을 구하시오.
풀이
$a_1=S_1=3$ (주의: $n\ge2$ 공식과 다르다)
$a_{10}=S_{10}-S_9=111-91=20$ → $23$
13
$\displaystyle\sum_{k=1}^{10}k(k+1)$의 값을 구하시오.
풀이
$\sum k^2+\sum k=385+55=440$
14
수학적 귀납법으로 $1+3+5+\cdots+(2n-1)=n^2$을 증명할 때, $n=k$일 때 성립한다고 가정하고 $n=k+1$일 때를 보이려면 양변에 무엇을 더해야 하는가?
풀이
$(k+1)$번째 홀수 $2(k+1)-1=2k+1$을 더한다
$k^2+(2k+1)=(k+1)^2$ → $n=k+1$일 때도 성립
15
$a_1=1,\ a_{n+1}=a_n+2n$일 때 $a_{10}$을 구하시오.
풀이
$a_n=1+\displaystyle\sum_{k=1}^{n-1}2k=1+n(n-1)$ → $a_{10}=91$
