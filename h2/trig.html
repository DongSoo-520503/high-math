삼각함수

대수 · 삼각함수 · 사인법칙과 코사인법칙

한 줄로 외우기

중3 삼각비를 원 위의 점으로 넓힌 것이 삼각함수다. 각이 돌아가면 사인·코사인 값이 물결처럼 되풀이된다.

왜 배울까?중3 삼각비는 직각삼각형 안의 예각만 다뤘다. 각을 360°보다 크게, 음수까지 넓히면 소리·빛·진자처럼 되풀이되는 현상을 식으로 쓸 수 있다. 사인법칙·코사인법칙은 직각이 없는 삼각형의 변과 각을 구하는 도구다.

1삼각함수

각을 시초선에서 회전한 양으로 보면 390°, −30°처럼 어떤 각도 생각할 수 있다(일반각). 고등학교부터는 각을 호도법으로 잰다: 반지름과 같은 길이의 호에 대한 중심각이 1라디안이고, π 라디안 = 180°.

반지름 r, 중심각 θ(라디안)인 부채꼴: 호의 길이 l = rθ, 넓이 S = ½r2θ.

원점이 중심인 반지름 1인 원(단위원) 위에서 각 θ만큼 돌아간 점을 P(x, y)라 할 때

sin θ = y,   cos θ = x,   tan θ = yx   →  sin2θ + cos2θ = 1

y = sin x, y = cos x는 주기가 2π, 치역이 −1 ≤ y ≤ 1이다. y = tan x는 주기가 π이고 x = π/2 + nπ에서 점근선을 가진다.

2사인법칙과 코사인법칙

삼각형 ABC에서 각 A, B, C의 대변의 길이를 a, b, c, 외접원의 반지름을 R라 하자.

공식언제 쓰나
사인법칙asin A = bsin B = csin C = 2R두 각과 한 변을 알 때
코사인법칙a2 = b2 + c2 − 2bc cos A두 변과 끼인각, 또는 세 변을 알 때
넓이S = ½ab sin C두 변과 끼인각을 알 때
예
b = 3, c = 5, A = 60°일 때 a2 = 9 + 25 − 2·3·5·½ = 19 → a = √19

A = 90°이면 cos A = 0이므로 코사인법칙은 피타고라스 정리가 된다. 코사인법칙은 피타고라스 정리의 확장이다.

꼭 외울 것

  • π 라디안 = 180°
  • 부채꼴: l = rθ, S = ½r²θ
  • sin θ = y, cos θ = x, tan θ = y/x (단위원)
  • sin²θ + cos²θ = 1
  • sin, cos 주기 2π / tan 주기 π
  • 사인법칙 a/sin A = 2R
  • 코사인법칙 a² = b² + c² − 2bc cos A
