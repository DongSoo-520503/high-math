지수함수와 로그함수

대수 · 지수와 로그 · 지수함수와 로그함수

한 줄로 외우기

로그는 "몇 제곱하면 되나?"의 답이다. loga b = x ⇔ ax = b. 지수함수와 로그함수는 서로 역함수라서 y = x에 대칭이다.

왜 배울까?세균 번식, 복리 이자, 방사능 감소처럼 "몇 배씩" 변하는 현상은 지수로 나타낸다. 지진 규모나 소리 크기(데시벨)처럼 아주 큰 범위의 수를 다룰 때는 로그를 쓴다.

1지수와 로그

중2 지수법칙은 지수가 자연수일 때였다. 지수를 0, 음수, 분수(유리수), 실수까지 넓혀도 지수법칙이 그대로 성립하도록 다음처럼 정한다(a > 0).

a0 = 1
a−n = 1an
am/n = n√am (a의 m제곱의 n제곱근)
예
2−3 = 1/8,  82/3 = (3√8)2 = 22 = 4

ax = b를 만족하는 x를 loga b라 쓴다(a는 밑, b는 진수, a > 0, a ≠ 1, b > 0). 예: 23 = 8이므로 log2 8 = 3. 밑이 10인 로그를 상용로그라 하고 log 100 = 2처럼 밑을 생략한다.

loga 1 = 0,  loga a = 1
loga MN = loga M + loga N
loga MN = loga M − loga N
loga Mk = k loga M
밑 변환: loga b = logc blogc a
예
log2 12 − log2 3 = log2 4 = 2

2지수함수와 로그함수

y = ax(지수함수)는 항상 점 (0, 1)을 지나고, x축(y = 0)이 점근선이다. y = loga x(로그함수)는 그 역함수라 점 (1, 0)을 지나고 y축이 점근선이다.

밑그래프방정식·부등식 풀 때
a > 1x가 커지면 y도 커진다 (증가)부등호 방향 그대로
0 < a < 1x가 커지면 y는 작아진다 (감소)부등호 방향 반대로
예
2x = 8 → 2x = 23 → x = 3
(1/2)x > 1/4 = (1/2)2 → 밑이 1보다 작으므로 부등호가 바뀌어 x < 2

꼭 외울 것

  • ax = b ⇔ x = loga b
  • a0 = 1, a−n = 1/an, am/n = ⁿ√(am)
  • log MN = log M + log N, log Mk = k log M
  • 밑 변환 loga b = log b / log a
  • 밑 > 1이면 증가, 0 < 밑 < 1이면 감소(부등호 반대)
