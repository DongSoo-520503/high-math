지수함수와 로그함수

대수 · 지수와 로그 · 지수함수와 로그함수

한 줄로 외우기

로그는 "몇 제곱하면 되나?"의 답이다. loga b = x ⇔ ax = b. 지수함수와 로그함수는 서로 역함수라서 y = x에 대칭이다.

왜 배울까?세균 번식, 복리 이자, 방사능 감소처럼 "몇 배씩" 변하는 현상은 지수로 나타낸다. 지진 규모나 소리 크기(데시벨)처럼 아주 큰 범위의 수를 다룰 때는 로그를 쓴다.

1지수와 로그

중2 지수법칙은 지수가 자연수일 때였다. 지수를 0, 음수, 분수(유리수), 실수까지 넓혀도 지수법칙이 그대로 성립하도록 다음처럼 정한다(a > 0).

a0 = 1
a−n = 1an
am/n = n√am (a의 m제곱의 n제곱근)
예
2−3 = 1/8,  82/3 = (3√8)2 = 22 = 4

ax = b를 만족하는 x를 loga b라 쓴다(a는 밑, b는 진수, a > 0, a ≠ 1, b > 0). 예: 23 = 8이므로 log2 8 = 3. 밑이 10인 로그를 상용로그라 하고 log 100 = 2처럼 밑을 생략한다.

loga 1 = 0,  loga a = 1
loga MN = loga M + loga N
loga MN = loga M − loga N
loga Mk = k loga M
밑 변환: loga b = logc blogc a
예
log2 12 − log2 3 = log2 4 = 2

2지수함수와 로그함수

y = ax(지수함수)는 항상 점 (0, 1)을 지나고, x축(y = 0)이 점근선이다. y = loga x(로그함수)는 그 역함수라 점 (1, 0)을 지나고 y축이 점근선이다.

밑그래프방정식·부등식 풀 때
a > 1x가 커지면 y도 커진다 (증가)부등호 방향 그대로
0 < a < 1x가 커지면 y는 작아진다 (감소)부등호 방향 반대로
예
2x = 8 → 2x = 23 → x = 3
(1/2)x > 1/4 = (1/2)2 → 밑이 1보다 작으므로 부등호가 바뀌어 x < 2

꼭 외울 것

  • ax = b ⇔ x = loga b
  • a0 = 1, a−n = 1/an, am/n = ⁿ√(am)
  • log MN = log M + log N, log Mk = k log M
  • 밑 변환 loga b = log b / log a
  • 밑 > 1이면 증가, 0 < 밑 < 1이면 감소(부등호 반대)

연습문제 15

공식 연습 5 · 교과서 응용 5 · 내신·수능 심화 5 — 풀이는 "풀이"를 눌러야 보입니다.

공식 연습1–5번

1
$8^{\frac23}$의 값을 구하시오.
풀이
$8^{\frac23}=(2^3)^{\frac23}=2^2=4$
2
$\log_2 32$의 값을 구하시오.
풀이
$2^5=32$ → $5$
3
$\log_3 6+\log_3\dfrac32$의 값을 구하시오.
풀이
$\log_3\left(6\times\dfrac32\right)=\log_3 9=2$
4
$\log_2 3\times\log_3 8$의 값을 구하시오.
풀이
밑변환: $\dfrac{\log3}{\log2}\times\dfrac{\log8}{\log3}=\log_2 8=3$
5
방정식 $2^x=16$을 푸시오.
풀이
$2^x=2^4$ → $x=4$

교과서 응용6–10번

6
방정식 $9^x-4\cdot3^x+3=0$의 모든 해의 합을 구하시오.
풀이
$3^x=t\ (t\gt0)$: $t^2-4t+3=0$ → $t=1,3$
$x=0,1$ → 합 $1$
7
방정식 $\log_2(x-1)+\log_2(x+1)=3$을 푸시오.
풀이
진수 조건 $x\gt1$
$\log_2(x^2-1)=3$ → $x^2-1=8$ → $x=3$
8
부등식 $2^{x+1}\gt8$을 푸시오.
풀이
$2^{x+1}\gt2^3$, 밑이 1보다 크므로 $x+1\gt3$ → $x\gt2$
9
$y=2^x$의 그래프를 $x$축 방향으로 $-1$, $y$축 방향으로 $2$만큼 평행이동한 그래프의 식과 점근선을 구하시오.
풀이
$y=2^{x+1}+2$, 점근선 $y=2$
10
부등식 $\log_{\frac12}(x-3)\ge-1$을 푸시오.
풀이
진수 조건 $x\gt3$
$-1=\log_{\frac12}2$, 밑이 1보다 작으므로 부등호 방향이 바뀐다: $x-3\le2$
→ $3\lt x\le5$

내신·수능 심화11–15번

11
$1\le x\le8$에서 $y=(\log_2 x)^2-4\log_2 x+5$의 최댓값과 최솟값의 합을 구하시오.
풀이
$\log_2x=t\ (0\le t\le3)$: $y=(t-2)^2+1$
최솟값 $1$ ($t=2$), 최댓값 $5$ ($t=0$) → 합 $6$
12
$a^{2x}=3$일 때 $\dfrac{a^{3x}+a^{-3x}}{a^x+a^{-x}}$의 값을 구하시오.
풀이
$p^3+q^3=(p+q)(p^2-pq+q^2)$ 이용
$=a^{2x}-1+a^{-2x}=3-1+\dfrac13=\dfrac73$
13
$\log_2 3=a$일 때 $\log_6 24$를 $a$로 나타내시오.
풀이
$\log_6 24=\dfrac{\log_2 24}{\log_2 6}=\dfrac{3+a}{1+a}$
14
$2^x=3^y=12$일 때 $\dfrac2x+\dfrac1y$의 값을 구하시오.
풀이
$x=\log_2 12$ → $\dfrac1x=\log_{12}2$, 마찬가지로 $\dfrac1y=\log_{12}3$
$\dfrac2x+\dfrac1y=\log_{12}4+\log_{12}3=\log_{12}12=1$
15
$\log 2=0.3010$일 때 $2^{100}$은 몇 자리 정수인지 구하시오.
풀이
$\log 2^{100}=30.10$ → 정수 부분 $30$ → $31$자리
